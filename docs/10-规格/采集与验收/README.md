## 这份目录负责什么

两件事合成一份，因为它们是同一个闭环的两头：**采到什么，就用什么验收**。

**它有一个反直觉的形状**：代码住 `offline/`，**触发点在线上**。触发发生在 `engine/vision` 与 `engine/state` 内部（槽自己发现不确定、组装发现账不平），而实现住 `offline/hardcase/`——所以中间必须有一个端口（§2）。

## 1 难例是什么：三层触发

**"什么算难例"不是一份统一清单**——不同的数据对象、不同的识别方法，坏法本来就不一样。所以触发分三层，各层各管各的：

| 层 | 谁产生 | 内容 | 归谁定 |
| --- | --- | --- | --- |
| **通用层** | 槽自己（字段级）· 组装（跨字段） | ① 置信度低 · ② **取值形态变粗**（精确 → 区间）· ③ 三态切换；④ [存疑清单](../状态层/快照.md) 里**跨字段**的那五类：**账目 · 同步 · 传播 · 采样 · 静默** | **本目录** |
| **方法层** | 每种方法自己的坏法 | 逐字模板对不上任何字形 · 色块面积比粘连 · 卷积分数低 · 背景差分失配 · 动画状态撞中间帧 …… | [识别方法.md](../视觉层/识别方法.md) 的「**天然失效模式**」列 |
| **资产层** | 资产自检 | [背景帧](../资产生成器/背景帧.md) §7 的差分失配 | 各资产规格 |

**方法层是一张「例外表」，不是全表。** 通用层已经覆盖大多数方法的坏法；**只有通用层看不见的坏法，才需要在那一列里单独写成一条落盘规则**（什么信号 → 落哪些帧 → 记什么）。

### 为什么不落盘的也有

存疑清单八类里，有三类**不进采集**：

| 类 | 为什么 |
| --- | --- |
| **读数** | 它**就是**槽自己带的那些信号（[快照](../状态层/快照.md) ⓪ 自己写着"这里只列名单"）——与通用层的字段级三条重复 |
| **时间** | 判定节拍跟不上，是**工具自己的时序问题**，不是"像素 → 字段"的质量问题。去处是[控制层 §7](../控制层/识别时机.md) 那句"这一段的时间不可信" |
| **动作** | 生效反馈未确认，属[接口层/执行与失败](../接口层/执行与失败.md) |

**边界一句话**：这份目录只采**抽象层（像素 → 字段）**的难例。时间归控制层，动作归接口层，各自有各自的上报去处——落进来只会把真难例稀释。

### 账目那一类最要紧

**通用层里最值钱的是「账目」。** 其余信号都是"**工具自己举手**"（某个槽知道它不确定），而零假事实最怕的方向恰恰是**工具不举手的错**——**漏检**：漏一个敌人，没有任何字段会举手。

[I4](../状态层/README.md) 是唯一抓得住它的：**残差非零**。它一次同时校验四个独立读数（敌人总数 · 已击杀 · 生命 → 漏掉 · 未出场），漏一个怪就让残差 +1 当场暴露。

> **代价要说清**：残差非零**不区分原因**——漏检是一个，召唤物（不计入总数但在画面上）是另一个。所以它是一条"**这里有账没算平**"的信号，不是"漏了一个怪"的结论。两者都值得落盘。

## 2 采集器跨层：一个端口

[代码结构](../代码结构.md) 规则一：**`engine` 永远不 import `offline`**。而触发点在 `engine/vision`、`engine/state` 内部，实现住 `offline/hardcase/`。

**所以它是一个端口**，登记在[契约层 §5](../契约层/README.md)：

| | |
| --- | --- |
| **谁发起** | engine（槽发现不确定 / 组装发现账不平） |
| **谁实现** | `offline/hardcase/`；`runtime/wiring.py` 接线 |
| **离线跑的时候** | **空实现**——离线验收不需要采集 |

它与设备 / 时钟 / 资产是同一类东西，因此也被[代码结构](../代码结构.md) 那条**端口完备性测试**覆盖。

## 3 采不到什么

**这一节是这份目录的诚实部分**——零假事实要的不只是"报得准"，还有"**知道自己哪里没看见**"。

| 采不到 | 为什么 |
| --- | --- |
| **漏检**（除账目能间接抓到的那部分） | 它不产生任何信号；账目只告诉你"账不平"，不告诉你漏了谁 |
| **关键帧之前的像素** | 不存在——[时序层 §5](../时序层.md) 只留被识别过的那几帧 |
| **两次采样之间的变化** | 观测迹是**采样**出来的；某字段变了又变回来会漏掉中间值 |
| **动作有没有生效** | [离线验收](离线验收.md) §2 那张不一致清单的第一条 |
| **没有真值的字段**（位置、血量） | 只能靠**自洽性**（I1–I4）与账目，**不能直接判对错** |
