## 1 一份落盘数据长什么样

| 部分 | 内容 |
| --- | --- |
| **原帧** | 整帧。**它是"本来就会留的那几帧"的子集**——[时序层 §5](../时序层.md) 只留被识别过的帧，采集**不额外取像** |
| **逻辑标签** | 帧号 · 关卡 · 词条 · **视图（常速 / 慢放）** · 时间态 |
| **当时的槽** | 本片实际取了哪些字段，各自的**三态 / 载荷 / 置信度** |
| **触发原因** | 哪一层 · 哪一类 · 涉及哪个字段或来源 |
| **存疑清单条目** | 结构化那四项：类别 · 涉及字段或来源 · 严重度 · 涉及哪几帧 |
| **成分表** | 多来源字段才有 |
| **戳** | 游戏版本 · 资产戳 · 分辨率与方向（**环境前提，不是资产维度**） |

**按类分目录**，分法就按 [README](README.md) §1 那三层、那几类。

**视图那一维不能省**：慢放是另一套投影（[投影](../资产生成器/地形与关卡资产/投影.md) §3），拿常速的帧去验慢放的链路，等于换了一道题。

## 2 定量上限

**必须有上限**，否则常态噪音（"某条通道长期未采样"这类）会把真难例淹掉。

| 上限 | 管什么 |
| --- | --- |
| 每类每局 | 同一类在一局里最多留几条 |
| 每类总盘 | 同一类在全盘最多留几条 |
| 每局总量 | 一局最多落几条（防某局异常刷屏） |

**淘汰：先到先留。** 理由是可复现——"保留最难的"需要一个排序，而排序本身要一个可信度，那又回到假精度。

**账目类豁免"每类每局"上限**：它天生稀疏，而且它是**唯一抓漏检的证据**，被上限挤掉就白搭。它仍受总盘上限约束，并按局去重。

**数值不在这里定**——它们是落地的事，现在给就是假精度。

## 3 用途：验收两份，外加一条依据

| 用途 | 是什么 | 要不要冻结 |
| --- | --- | --- |
| **基准集** | 一批样本 + 真值，用来算"有没有说假话" | **冻结** |
| **回归输入** | 同一批帧喂回去，比对上次的输出 | **冻结** |
| **资产回流** | 难例是[特征库](../资产生成器/特征库.md) §4 的回流来源之一——它驱动**标定**（体型、区域可分性那几条阈值） | 不冻结，越用越少 |
| ~~训练数据~~ | **不是训练集**——它是"**将来要不要训模型、训哪一步**"的**依据** | — |

**"训练数据"这一样改过口径。** 基线 §5.5 原来把它与基准集、回归输入并列成"三样东西"，但 [D-全局-06](../../20-决策记录/全局.md) 已经定了**不上训模型**，否掉的理由正是"**在还不知道哪一步最不准之前训模型，是在猜**"——而**难例集恰好就是回答"哪一步最不准"的那个东西**。所以它**已降级成"那条决定要用的输入"**，而不是一份数据集。这也正是 D-全局-06 留的那句"延后到确实需要时"。

**冻结纪律**：**拿基准集调过参，它就不再是干净基准**。要调参就换一份，并在验收记录里写明**基准是第几版**。

**顺带**：基准集与回归输入都要冻结，所以**不需要分池**。
