# 离线验收

> 状态：讨论中 ｜ **跑到槽 · 不一致清单 · 上界是判据、下界是仪表**已定

**采集与验收**的正文之一——职责、三层触发与跨层端口见 [README.md](README.md)；落盘格式见[难例采集.md](难例采集.md)。

## 1 跑到哪一级

**把录下来的帧喂回线上识别链路，跑到「槽」为止。**

| 跑到哪 | 验得到 | 验不到 |
| --- | --- | --- |
| **槽**（字段级：三态 / 载荷 / 置信度 + 存疑清单） | [开题状态](../../00-总览/开题状态.md) A4 判据②「**降级路径确实生效**」——降级是**字段组装**的行为 | — |
| 原语结果（矩形 + 分数 + 载荷） | 单个方法有没有命中 | 降级策略；A4 判据②落空 |

这是「视觉层必须能被离线驱动」那条地基约束的**验收手段**（[概念设计共识](../../概念设计共识.md) §5.4 第 3 条）。

## 2 离线复刻与线上的不一致（§5.4 第 3 条要求显式记录）

| 不一致 | 影响 |
| --- | --- |
| **注入只记一笔、不真的点**（[设备层](../设备层.md) §5 的 replay 适配器） | 没有真实动作生效——**"动作有没有生效"这一类结论离线得不到** |
| **照帧号走、无视概率触发** | 已知的账（[时序层 §6](../时序层.md)）：同一条件在不同局落在不同帧，重放不跟着变 |
| **节奏与等待被跳过** | 依赖真实等待的读数（"面板滑出来了"）离线得不到 |
| **资产戳可能与录制时不同** | 用当前资产跑旧帧，会把**版本差异**算成**识别退化** |

**这张表决定哪些结论离线能得、哪些不能**：能得的是"**像素 → 槽**"这一段；不能得的是"**动作有没有生效**"。

## 3 量的是什么

**只有一条判据，外加一份仪表。**

| | 形态 | 为什么 |
| --- | --- | --- |
| **上界：零假事实** | **判据** | 有**客观对错**——报错了就是错了，不需要任何样本集 |
| **下界：不懦弱** | **仪表** | "该报多少"**取决于场景**——一片本来就全是空地，"什么都没报"是对的；线画在哪都是拍的 |

### 判据：零假事实

**报出来的断言，不许与事实冲突。** 逐形态对：

| 报了什么 | 事实 | 算不算假事实 |
| --- | --- | --- |
| **精确 v** | ≠ v | **算** |
| **区间 [lo,hi]** | 真值不在里面 | **算**（区间就是"真值在这段里"这个断言） |
| **下界 lo** / **上界 hi** | 真值落在那一侧之外 | **算** |
| **未知** / **未采样** | — | **永不算** |
| **已采样但为空** | 其实有东西 | **算**（凭空说没有） |
| **该报的没报** | — | **算**（静默）——**只能靠账目抓**（[README](README.md) §1） |

**真值从哪来——免费的那两侧**：**卡位**（第几张卡是谁）← **我们自己下达的部署记录**；**敌人类型** ← **路线资产**（含出怪）。这两样本身就是答案，不需要人工标。

**假事实的第一道网不在采集里**：[I1–I4](../状态层/README.md) 是**在线自检**，当场就暴露。采集抓的是不变量抓不到的——主要是**静默**那一类。

### 仪表：不懦弱

**它不做成判据**（用户裁定）：**线上没有一个东西能说"这一片是清晰的"**——"清晰样本"是离线测试集的概念，要做成判据就得先人工标一批，那正是被否掉的那条路。

**所以它只是一份仪表**，与[算子清单 §4](../接口层/算子清单.md) 的"AI 反复要看原帧"、[快照](../状态层/快照.md) 的"取图的频率"同一个用法。四个信号**运行时就算得出来，零标注**：

| 信号 | 从哪来 | 抓什么 |
| --- | --- | --- |
| **弃权率** | 只在**真值已知**的字段上——真值就是上面免费的那两侧，所以"真值已知"是**运行时的属性**，不是人的判断 | 该报的没报 |
| **调用次数 vs 给出读数的次数** | 纯计数 | **方法是死的**——被调几千次、一次"有值"都没给过 |
| **置信度分布** | 该方法每次给出读数时的置信度（原语自算） | 整体长期偏低 → **方法不行，或者用错了地方** |
| **逃生舱频率** | AI 调 `看原帧` 的次数 | 快照不够用——**这条在线上，不在离线验收里** |

**要诚实的两点**：① 免费真值只覆盖**两个字段**（卡位、敌人类型），弃权率**覆盖面很小**，后三条才是主力；② 置信度是原语的**自评**，它自己也会错（高置信度但认错）——所以它**单独撑不住零假事实**，上面那条判据不能省。

**谁来读这份仪表**：**AI**（它在环里，看得见某个字段一直没值）；**人 review 时**（把四个计数并进验收记录）。
