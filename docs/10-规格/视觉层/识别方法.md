# 识别方法

> 状态：讨论中 ｜ **这是一份底子，允许往上增补**——不追求第一次就穷举，缺什么加什么；**「天然失效模式」列已填**（设计层的坏法，阈值留空）

对应代码：`src/ark/engine/vision/`。

## 它是什么，跟原语什么关系

| 层 | 回答什么 | 谁定 |
| --- | --- | --- |
| **原语** | **问什么**（"这个图标在不在" / "这串数字是什么"） | **七条**，见 [原语.md](原语.md)；结果的形状见[契约层](../契约层/README.md) §1 |
| **方法** | **怎么做到**（卷积 / 颜色统计 / 环形角度 / 动作账） | **本文件** |

**AI 注册一个效果字段时，编排里每一环挑的就是"方法"**（**一个环 = 本表里的一行**，方法必须是原子的）。同一个效果往往有几条链路，挑哪条决定它可不可行、准不准、要不要资产——所以这张表就是**注册窗口里的那张菜单**；而"**怎么把几环串起来**"归[状态层/字段编排.md](../状态层/字段编排.md)。

## 每一行记八件事

`答哪个原语 · 认什么 · 要什么输入 · 要哪些资产 · 天然失效模式 · 误差单边还是双边 · 有没有副作用 · 跑在什么时间态`

**「答哪个原语」是本表与[原语.md](原语.md) 的唯一接口**：那张映射只写在这一列里，别处不再列一遍（[原语.md](原语.md) §1 说的是"见本列"）。**C 族与 D 族不出现在这一列里**，理由在[原语.md](原语.md) §4。

**"单边还是双边"是最要紧的一列**：单边只是不准（宁可报下界），**双边就是假事实**——认错一个值比漏认一个值危险得多。

**「天然失效模式」那一列已经填了**（各表的最后一列）——填的是**设计上就知道的坏法**；**多容易坏、阈值多少，留空等真机**，那才是实测才能给的东西。

**标了 `⚠` 的是「通用层看不见的坏法」。** 槽自己带的那三条信号（置信度低 / 形态变粗 / 三态切换）**抓不到它们**——最典型的是**漏检方向**（"说没有其实有"）：字段会报"已采样但为空"，置信度还正常。所以这几行**必须在采集侧单独写成一条落盘规则**（什么信号 → 落哪些帧 → 记什么），见[采集与验收](../采集与验收/README.md) §1 的方法层。**其余行不用单列**——通用层已经覆盖，这就是"方法层是例外表、不是全表"的意思。

**有副作用的只有一类**：点开技能详情（可能误放技能），见[技能详情通道.md](技能详情通道.md)。

**「要资产吗」那一列里的资产，从哪来 → 见[资产生成器/特征库.md](../资产生成器/特征库.md)**（那份文件就是按这张表的这几列对齐的）。

## A 像素统计

| 方法 | 答哪个原语 | 认什么 | 要什么输入 | 要资产吗 | **天然失效模式** |
| --- | --- | --- | --- | --- | --- |
| **亮区比例** | `measure` | 条状量：血条、技力、弹药 | ROI + 方向 | 否 | 被特效或别的 UI 盖住 → 比例读低（单边） |
| **颜色 / 色相判定** | `classify` | 条的含义：绿=充能中 · 橙=生效中 | ROI | 否 | 特效染色把两色拉近 → 认成另一种含义（**双边**） |
| **环形进度角度** | `measure` | 环形倒计时、充能环 | ROI + 圆心 | 否 | 圆心偏了 → 角度整体偏移；环被遮挡 |
| **环上色块的角向分布** | `heading` | **我方干员的朝向**（脚下白环上的黄箭头） | ROI + **圆心** | 否 | **立绘自带的黄色像素被当成箭头 → 报一个错方向**（在**特定干员**上反复出现，**系统性**）**⚠**；看不到箭头 → 见[首轮探索/录轴](../首轮探索/录轴.md) §3（那条是上游的约定，不是本方法的性质） |
| **存在性搜索** | `exists` · `locate` | 图标在不在：黄菱形、暂停按钮、结算画面 | 可外扩的 ROI + 图标模板 | **是** | 图标被盖住 → **说"没有"其实有**（漏检方向）**⚠** |
| **色块面积比** | `count` | 密集区里"至少有几个"（**下界**） | ROI + **单怪色块资产** | **是** | 粘连 → 下界偏低（保守，不算假事实）；被特效改色 → 面积算错 |
| **背景差分** | `exists` · `locate` | "这里和干净关卡帧不一样" → 单位候选区（**存在性**，不给身份） | 当前帧 + **干净关卡帧资产** + 战场 ROI | **是** | **资产失配**（视图没切 / 版本变了）→ 整片假阳性，归**资产层**；单位与背景同色 → **漏检** **⚠** |
| **时间统计（帧间稳定性）** | `classify` | 这个像素是常驻的（单位）还是闪的（特效） | **连续帧** | 否 | 只抓到一帧 → 判不了（落成未采样） |
| **距离变换分离** | `count` | 一片粘连轮廓里"至少有几个" | 单位掩码 + **单怪占位面积** | **是** | 单怪面积标定错 → 下界系统性偏；粘连严重 → 分不开（报不可数，诚实） |

## B 模板与卷积

| 方法 | 答哪个原语 | 认什么 | 要什么输入 | 要资产吗 | **天然失效模式** |
| --- | --- | --- | --- | --- | --- |
| **逐字小模板** | `measure` | 数字：费用、倒计时、层数、生命 | ROI + 字形表 | **是** | 对不上任何字形 → 干净降级成未知；**逐位歧义**（`2?` → `[20,29]`）**⚠** |
| **小模板定位** | `exists` · `locate` | 元素在哪：干员、备战席卡片 | ROI + 模板 | **是** | 元素被遮挡或移出 ROI → 说"不在"其实在（漏检方向）**⚠** |
| **卷积分类** | `classify` | 身份（敌人类型）· **效果的特效** | ROI 或全屏候选 + 特征库 | **是** | 分数低 → 降级；**候选重叠**（两个类型都中等分）→ 挑错一个（**双边**） |
| **动画状态分类** | `classify` | 状态：冻结、眩晕等 | **连续帧** + 人工采样样本 | **是** | **撞中间帧** → 认成相邻状态，而分数可能并不低 **⚠** |
| **帧差 / 出手时刻** | `event_time` | 出手那一瞬间 | 连续帧 + ROI | 否 | 取像帧率不够 → 错过那一瞬 → 报"没出手" **⚠** |
| **区域可分性分类** | `classify` | 这一片能不能逐个分开：可逐个体 / 可数 / **不可数** | 候选区域 + **难例集** | **是**（难例集） | 边界档（可数 / 不可数）判错 → **结论本身错**，而它就是一个分类结果，没有别的信号 **⚠** |

按 [D-全局-06](../../20-决策记录/全局.md)，卷积这一类先落在**简单卷积 / 特征匹配**上，**不上训模型**。

## C 非视觉（算 / 记）

**本族没有「答哪个原语」这一列**——它们不是原语，理由在[原语.md](原语.md) §4。

| 方法 | 认什么 | 要什么输入 | 要资产吗 | **天然失效模式** |
| --- | --- | --- | --- | --- |
| **动作账推算** | 我们主动给的效果、消费、回费 | 指令记录 + 数据库 | 否（要数据库） | 与游戏**脱同步** → 整族偏（进「同步」类，通用层看得见） |
| **技能窗口推算** | 技能何时开始 / 结束 | 橙条读数或我们的指令 + 数据库时长 | 否（要数据库） | **数据库时长错 → 系统性偏，没有任何信号** **⚠** |
| **几何判定** | **谁在范围内**（形状 ∩ 各单位位置） | 形状（数据库 + 朝向 + 位置）+ 位置读数 | 否（要数据库） | 位置是区间 → 结论**三值**；**"判不了"不等于"假"** |
| **效果链推算** | **由 A 触发的 B** | 数据库的触发关系 | 否（要数据库） | 触发关系缺失 → 整族落成未采样（看得见） |
| **合成规则** | 同名取最高 / 相加 / 相乘 | 数据库的效果定义 | 否（要数据库） | **漏一种规则（例如"覆盖"）→ 值错而形态正常** **⚠** |
| **时间推算** | 时效、随时间递增的量 | 游戏时间 + 演变规则 | 否（要数据库） | 游戏时间失准 → 属「时间」类，**不进采集**（[采集与验收](../采集与验收/README.md) §1） |
| **位置序列差分** | 移动速度 | 位置读数 + 游戏时间 | 否 | 位置有区间 → 速度也是区间（形态自洽） |
| **跨快照自检** | 单调性与不变式（I1–I3） | 前后两片快照 | 否 | 它**本身就是检测器**，不适用 |

**C 族要特别注意**：算类与记类**没有置信度**（[契约层](../契约层/README.md) §1），所以通用层的第一条"置信度低"**对它们完全无效**。它们只能靠三态、形态，以及跨字段的**账目 / 同步**——这也是方法层对 C 族比对 A、B 族更要紧的原因。

**C 族不是"退而求其次"。** 铃兰那个例子：天赋让**被停顿的敌人**在下一瞬间起受到等长时间的 20% 脆弱，三技能把第二天赋提到 2.0 倍、并把范围内所有敌人停顿——整条链**只需要读橙条和敌人位置**，停顿落进移动速度（一档的成员，不必注册），脆弱 40% 由 C 族推出来，**一条视觉通道都不用**。

所以判据不是"有没有特效"，而是**"输入齐不齐"**——读只是产出链路里的一条。

## D 兜底

**它不是做法，也没有原语可答**——它是"拿不到"本身（[原语.md](原语.md) §4）。

| 方法 | 认什么 | 要什么输入 | 要资产吗 | **天然失效模式** |
| --- | --- | --- | --- | --- |
| **不注册** | 明说"这个我拿不到" | — | 否 | 它**就是**降级本身，没有"坏法"；真正的坏法是**该注册的没注册**（属 [AI 侧](../AI侧/README.md)） |

**兜底不是空行**：拿不到就报未采样 / 未知，而不是编一个值。

## 已定：数字一律走固定字形模板

费用、再部署倒计时、备战席卡片上的数字——**这个游戏的数字只有 0-9 与小数点，字体与位置都固定**。

- 用小模板匹配（每个字形一张），**不上通用 OCR**；
- 通用 OCR 的失败模式是"认成别的字"，那正是假事实；
- 固定字形匹配的失败模式是"这个位置对不上任何字形"，可以干净地降级成"未知"。

**已查，结论改了**（T3 落地）：**对不上任何字形**要分两种情形，**不能一律报未知**——

- **整块都没笔画**（数字区被遮挡 / 涂黑）→ **未采样**（[状态层/全局与HUD](../状态层/全局与HUD.md) §当前费用 的降级触发写的就是"数字被遮挡 → 未采样"）；
- **只有某一位对不上**（其余位读到了）→ **区间**，那一位的候选是全部十个数字：`1?` → `[10,19]`。**比整个字段报未知诚实得多**，也保住了已经读对的那几位。

**为什么不是「已采样但为空」**：那一支是"看了，那里没有东西"；这里是"那里有东西，只是认不出"——混掉就是假事实。

## 已知的缺口（往上添的方向）

- **多帧时序类**：除了动画状态与出手时刻，可能还缺一个通用的"这一帧和上一帧比，变了没有"；
- **置信度怎么算，规格里没给**：契约层只说它是"原语算出的连续量"，**没有刻度**。T3 的实现里自己定了两套：数字 = 逐位最弱那一位的相关系数；条 = 定下这次读数的那个判据两侧隔了多远 ÷ 255。**两套口径不一样，也没和别的字段对齐**——等第二个读数链落地时一起定，否则每个字段各定一套就没法比；
- **模板归一化用了自己写的双线性缩放**（不让视觉层为一个缩放去依赖图像库）：建表与读表都用它，所以自洽；但**换一个缩放实现重建表就重现不出来了**——一条隐性耦合，等真要换库时再收；
- **模板是"多帧平均"的**（`1` 有 4 张样本、`9`/`3`/`5`/`6` 各 2 张、其余各 1 张）：平均抹平了亚像素抖动，也把边缘抹软了。**"取最清晰的一张"没试过**，等出现认错再比；
- **遮挡 / 掩码类**：从原图取掩码、只匹配没被盖住的部分——概念文档 §5.4 提过；我方干员用不上，敌人侧可能要用；
- **表格里那三列（单边双边 / 副作用 / 时间态）现在没填**：等真机实测再补，现在填了就是假精度。**「天然失效模式」那一列已经填了**——它填的是"设计上就知道的坏法"，不需要真机；同列的阈值与概率仍然留空。
