## 判死与再部署：换一个信息源，而不是给同一个信号加滤波

原本的写法是"场上两条都找不到 → 判死"，然后我们担心它需要防抖（一次丢失就产生假事实）。

**这个担心可以直接删掉，因为那个信号根本不该用。** 备战席的卡片上有更直接的信号：

实例：[战斗演示图——备战席的再部署倒计时.jpg](../../../tests/示例图片/战斗演示图——备战席的再部署倒计时.jpg)。

| 卡片状态 | 含义 |
| --- | --- |
| **红罩 + 灰色圆环 + 白色环形进度（顺时针延伸）+ 中央数字** | 该干员**不在场上**，正在再部署倒计时；中央数字就是剩余秒数（实测到小数位） |
| 普通卡片 | 可重新部署 |

**为什么不需要防抖**：

- "场上找不到条"是**否定证据**——它天然会漏，只能靠时间滤波补救；
- "卡片在倒计时"是**肯定证据**——看到就是看到。

> **能用肯定证据，就别用否定证据。**

三个附带好处：

1. **位置固定**：备战席是静态 UI 栏，ROI 钉死即可，识别成本远低于全画面搜索（这正是 §5.4 第 1 条"定死环境"的红利）；
2. **顺带白拿再部署剩余时间**——那个数字就是排轴要用的"还有多久能再下"，判据从一个布尔升级成一个可计算字段；
3. **不需要区分"死了"还是"被我们撤退"**——撤退是我们自己下的指令，答案在我们手里。

**同一个量有两路读数**：环形进度的角度、中央的数字。两者不一致时**上报冲突**，而不是挑一个。
