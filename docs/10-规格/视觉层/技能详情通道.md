# 技能详情通道：一个"有副作用的读取"

实例：[干员演示——多层技能的效果展示.jpg](../../../tests/示例图片/干员演示——多层技能的效果展示.jpg)。

点击**已部署的干员**会同时做三件事：

1. **进入慢放**——这正是概念文档 §2.2 第 10 条说的慢放进入方式；
2. 打开**干员技能详情面板**（从左侧滑出）；
3. 在干员旁显示**技能按钮**（带层数数字与充能进度）。

面板里能读到的东西，按对我们有没有用分：

| 面板内容 | 有用吗 |
| --- | --- |
| 干员名 / 等级 / 攻击 / 防御 / 法抗 / 阻挡 | **没用**——静态属性，数据库里有 |
| **生命 `4227/4227`** | **有用**：比场上蓝条的像素比例精确得多 |
| 技能名 / `自动回复`·`手动触发` 标签 / 描述全文 | 半有用——这是**数据库该有的东西**，顺带说明**游戏自己就按这两轴标注了技能** |
| **技能图标旁的层数数字** | **有用**：场上读不到（见 7.1） |
| **技能图标上的绿色滤镜覆盖 + 充能读数** | **有用**：当轮充能进度 |

### 7.1 它读的是场上看不到的那几条

**可多次充能的技能，第 2 轮起的充能进度不在场上的技力条里显示**（技力条只显示第一轮）。

**层数在场上默认也不显示**——如果这个技能同时是手动释放的，**已充能次数会被黄色菱形的可释放标识抢掉显示位置**。

**但选中这个干员之后，两者都变成原生数字**：技能按钮旁一个**层数数字**，按钮上一个**当轮充能读数**（例图里是 `2` 与 `3/11`）。两者都是固定字形数字，模板匹配即可。

于是顺序是：**先看场上有没有黄色菱形（无损，见 §7.2）；要精确到层数，才点它（有损）。**

**上限不用读**：`可充能 3 次` 写在技能描述里 → 查数据库；界面只给"当前几层"。与弹药总数同理（§2）。

**而且"多充能"是数据库里的一个属性，不是视觉层的默认值。** 印象里"可多次充能 且 手动释放"的干员只有一个，但正确做法是**把这一类在数据库里标出来**：

- 数据库标成"单层"的干员 → 层数**恒为 1**，这是**推理**，不是猜测；
- 数据库里**缺**这个属性 → **报错**，而不是静默按 1 处理。

"默认 1"和"上限为 1 所以恒为 1"看起来结果一样，但**遇到新干员时的行为完全不同**：前者静默出错，后者当场拦下。

### 7.2 读取有副作用，而且不小

**点击干员本体时，技能按钮就在旁边——点到它就会真的释放技能。** 这不是"读错了"，这是**改变了战局**。

于是读取必须分成两类，设计上分开对待：

| | 例子 | 副作用 |
| --- | --- | --- |
| **无损读取** | 搜血条 / 技力条 / 黄色菱形，读固定 UI 栏 | 无 |
| **有损读取** | 点干员开详情 | **可能误触技能按钮而真的释放技能** |

暂定规则：**进详情后必须核验面板确实出现**；没出现就得考虑"可能已经误放了技能"，如实上报，不能当作一次普通的读取失败轻轻放下。

### 7.3 但有一个零风险的慢放入口

**点击备战席的干员卡片**（包括处于再部署倒计时的）**同样进入慢放并打开技能详情，而且此时放不了技能，只能看**。

于是分工很清楚：

- **想进慢放 → 点备战席卡片**，不会误放任何东西；
- **想读某个已部署干员的层数 → 才需要点它本体**，有风险，必须核验。

### 7.4 慢放的代价

慢放与详情面板是同一个动作的产物，所以**慢放会遮住战场最左约四分之一**——这条属于时间态控制的副作用，正文在 [控制层/](../控制层/时间态.md)。

另外，**什么时候做识别**也归控制层——它有三档（时间判定期间不识别、条件判定期间低频、关键时段高频），见 [控制层/](../控制层/识别时机.md)。

### 7.5 读取的时机前提：先点，再暂停

**暂停状态下点不动在场干员**，所以面板不是"想读就读"。可行的顺序是：

> **先点开某个在场干员 → 再进入暂停。**

此时面板留着、继续可读，而游戏时间已经冻结——**读本身不花代价**。代价全落在"点"这一步：

- **单次暂停只能覆盖一个干员**：想读第二个，就得再走一次"点 + 暂停"；
- 每一次"点"都发生在暂停之外，**游戏时间会走掉一小段**（慢放下墙钟的十分之一，可由费用读数测出，见 [时间基](../../30-专题/时间基.md) §3）；
- 点在场的干员就带着 §7.2 那条**误放技能**的风险。

**但有一处可以白拿**：慢放的进入方式本来就是点击干员。走两段式条件时，**"进慢放"那一步点的那个干员，面板是顺带到手的**——谁被点、谁的面板到手。所以"进慢放点谁"是个可以指定的选择，见 [控制层](../控制层/时间态.md)。

**基础值不走这条通道。** 它在**开战前**于干员养成面板里读，落在资产侧的**卡面与指纹**（[时序层](../时序层.md) §3、[卡面与指纹.md](../资产生成器/卡面与指纹.md)）；战斗中的面板只服务**有效值**（见 [状态层/基础数值.md](../状态层/基础数值.md)）。
