## 坐标精度的分工

| 用途 | 坐标精度要求 | 手段 |
| --- | --- | --- |
| **识别**（血条 / 技力条 / 菱形） | **低** | 用格子位置开一个**宽容窗口**去搜，偏移被窗口吸收 |
| **部署点击**（格 → 像素） | **高** | 必须准，见 [地形模型](../../30-专题/地形模型.md) 的「尚未定」 |

也就是说：**高台的高度偏移只影响后者**。识别侧一个数都不用管——"窗口开宽一点"就吸收掉了。
