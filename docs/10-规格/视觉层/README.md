## 这份目录负责什么

## 坐标精度的分工

| 用途 | 坐标精度要求 | 手段 |
| --- | --- | --- |
| **识别**（血条 / 技力条 / 菱形） | **低** | 用格子位置开一个**宽容窗口**去搜，偏移被窗口吸收 —— **但只保到"丢读数"，不保证读数不变**（实测：锚点偏 +12 px 那一档，填充短的块会丢读数，见 [D-全局-33](../../20-决策记录/全局.md)） |
| **部署点击**（格 → 像素） | **高** | 必须准，见 [地形模型](../../30-专题/地形模型.md) 的「尚未定」 |

也就是说：**高台的高度偏移只影响后者**。识别侧一个数都不用管 ——"窗口开宽一点"就把**偏移**吸收掉了（**注意**：吸收的是偏移，**不是"读数一定不变"** —— 偏移大到一定程度会**丢读数**，见 [D-全局-33](../../20-决策记录/全局.md)）。
