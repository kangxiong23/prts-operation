# 点名区域有没有敌人

> 状态：讨论中 ｜ **方案已成，一条都还没实测**：窗口长度、面积门、纹理门全部待真机

`exists` 原语在**「这一格现在有没有敌人」**这个问法上的**组合方式与判定顺序**。单个方法本身的底子在[识别方法.md](识别方法.md)，原语的载荷词表在[原语.md](原语.md)。本文件只回答另外三件事：**挑哪几个方法、按什么顺序、谁说了算**。

## 0 它服务什么：条件检测，不是查询

用法是「**当某格出现敌人的时候，暂停一次**」这类触发器：AI 给一个格，系统每帧评估，成立时触发。三个推论写死在这里：

- **粒度是「格」**（用户 10-18 定）。格是 AI 全部决策的单位（目标格、路线、阻挡位），像素只在调试与 ROI 追溯里出现；
- **形态是扫描式**：一帧进、逐格出。条件检测要的是**边沿**（上一帧没有、这一帧有），而边沿必须由**持有历史的那一层**算 —— 所以历史留在视觉层，不推给调用方，也就不会有"每个调用方各存一份格表历史"；
- **判据输出的是"这一格现在有没有候选"，触发是它在时间上的变化。** 两者分开：本文件只产出前者。

**它不回答**：这是哪一个敌人 · 这一格有几个 · 它还剩多少血。这三件事各有各的链（类型走分类，个数走 `count`，血量走[敌条那条链](敌方单位.md)）。

## 1 输入与输出

| | |
| --- | --- |
| **输入** | 一帧**原始抓帧**（不是录像帧、不是暂停帧）+ **格表**（格 → 屏幕多边形） |
| **输出** | 逐格三态：**有** / **干净** / **看不出**；每格附**每条判据的余量**与**未确认 / 已确认** |
| **不给** | 不给置信度总分 —— 与敌条那条链同一条纪律：**每样带形态 + 余量** |

**三态不是新词。** 它落在[原语.md](原语.md) §1 给 `exists` 的允许载荷上：**有 = 精确(有) · 干净 = 精确(无) · 看不出 = 未知**。

**格表是参数，不是本层产生的**：视觉层不懂地形语义，只按调用方给的多边形往里填判定；格 ↔ 屏幕的换算是[投影](../资产生成器/地形与关卡资产/投影.md) 的事。

**帧率是硬前提。** 取像往返约 1 秒（[通道耗时](../../30-专题/通道耗时.md)），所以"某一格在极短时间内被穿过"是**采样直接漏掉**的，不是判据算错 —— 这一档不在这里解决，由控制层的[识别时机](../控制层/识别时机.md) 走慢放再判。

## 2 为什么不能只靠一条判据

三条路被否掉，理由都不在本文件里：

- **账（路线资产）不参与判定**（用户 10-18）。敌人位置的主通道确实是推算，但要把加速、减速、停顿、眩晕、我方阻挡 / 推拉 / 诱导 / 传送 / 冻结 / 睡眠 / 束缚、场地机制、推箱全部算进去才准，工作量与精度都不划算。**账只用来给 AI 排兵布阵做参考**（大概什么时候到、走哪条路）；
- **不建外观库**：干员上场后是什么样、特效是什么样，都不建库（工作量原因）。所以任何"先认出它是什么再判"的路子都没有基础；
- **不能用"变成什么样"当判据**：受击不白闪、阴影图层太低容易被盖、阻挡位移只对部分敌人生效 —— 三条都试过了，见 §8。

剩下的判据只有两类原料：**时间**（多久没变、断没断过）与**空间**（换了没有、新内容像不像一块纯色）。下面六条全部由这两类原料做出来。

## 3 六条判据

| 编号 | 判据 | 量的什么 | 专门分开哪两种 | 已知失效 |
| --- | --- | --- | --- | --- |
| **J1** | 干净关卡帧差分 | 这一格和空战场不同 | 基底，**不单独下结论** | 资产失配（视图 / 版本 / 美术） |
| **J2** | **归一化局部相关** | 内容还是原来那块地板吗 | 半透明特效 ↔ 真覆盖 | 对比度极低时相关没有意义 |
| **J3** | **内部纹理 / 边缘密度** | 新内容是不是一块纯色 | 纯色特效（白地板那类）↔ 单位（**含怪海、含大体型**） | 雪花 / 粒子 / 亮斑；纯色单位 |
| **J5** | **短窗交集吸收** | 最近两三帧里是不是一直在 | 长期不变的东西 ↔ 新东西 | 静止的敌人会被吸收（**兜底见 §7**） |
| **J6** | **多帧并集占位** | 我方干员到底吃掉了哪些像素 | 我方干员 ↔ 别人 | 学习期内可能学到脏帧（靠遗忘恢复） |
| **J4** | **中断史** | 自出现起断过没有 | 干员动作残差、脉冲特效 ↔ 真的状态改变 | 出现后头几帧判不出来（落"未确认"） |
| **J7** | 血条（橙 / 红） | 已经被打过的敌人 | 确认 | 满血无条 |
| **J8** | 接地阴影 | 贴地的暗斑 | 辅助确认 | 图层低、易被遮挡 |

**J7 / J8 只往余量里写，不参与判定**（用户 10-18）。它们负责补漏：判据说干净、但有条或阴影时，报出来但标成"靠补漏"。

## 4 正交表：J2 × J3

两条判据各回答一个**定性**问题，交叉出来的不是分数，是一张**四格判定表**：

| J2 相关 | J3 纹理 | 是什么 | 判 |
| --- | --- | --- | --- |
| **高** | 高 | 地板还在，只是被染色 / 压暗 | **不报**（半透明特效） |
| **高** | 低 | 地板还在，本来就很平（暗地、雪地） | **不报**（干净） |
| **低** | **高** | 换了内容，而且新内容有结构 | **报**（单位，**怪海落在这里**） |
| **低** | 低 | 换了内容，而且是纯色 | **不报**（白地板那类不透明特效） |

**为什么不是尺度**：用"跨了几格"去剔特效，会把**怪海**一起剔掉 —— 怪海本来就跨多格。纹理这条的好处是它的方向是正的：**怪海不是要绕过的困难，而是纹理最亮的地方**。

**这张表的前提是逐格算**：特效、被盖住的干员、站在特效里的敌人，在连通域上是**一整片**，整片算一次相关和纹理得到的是混合统计量，没有意义 —— 更糟的是整片一旦判成特效，**里面的敌人会跟着被剔掉**。所以判定单位下沉到格。

## 5 流程

1. **干净帧差分** → 这一格和空战场不同的掩码（J1）；
2. **减去不动像素**（J5，短窗）· **减去我方干员占位**（J6，并集 + 遗忘）；
3. **剔除成群散点**：小块的**个数**达到阈值且彼此分散 ⇒ 整批剔除。**按"成群"剔，不按"面积小"剔**（用户：小怪没粒子那么小；阈值仍要按最小那一档怪的面积留余量）；
4. **逐格算 J2 · J3**，走 §4 的四格表；
5. **J4 连续确认**：落在"报"那一格的，观察 k 帧，中途断过就撤；
6. **J7 / J8 补漏**（只写余量）；
7. **触发** = 这一格从"无候选"变成"有候选"的**边沿**。

## 6 三个关键定义

**J5 短窗交集**：当前帧的差异掩码，与**最近两三帧**的同款掩码取交，**交集扣掉**。不是"学习一个背景模型"，所以没有学习期、学不到脏东西；两帧就生效。效果是**任何在最近几帧里一直在的东西都消失** —— 包括地形、装置、干员主体、以及**静止的敌人**。后者是有意接受的，兜底见 §7。

**J4 中断史**：J5 扣完之后剩下的那一层残差，它的性质很具体 —— **有的帧被覆盖、有的帧没被覆盖**（干员攻击 / 转身撑开的边缘就是这样）。所以对每个残差像素记"**自出现以来断过没有**"：

- 断过又回来 ⇒ 剔除（动作边缘、脉冲特效、雪花粒子都会翻覆）；
- 自出现起没断过 ⇒ 保留为候选。

它是**两个时间尺度上的两个不同问题**：J5 问"一直在吗"，J4 问"出现之后断过吗"。两者不叠加吸收，所以不会互相抵消。

**J6 并集 + 遗忘**：干员所有出现过的遮挡都进占位（**并集**），窗口滑动（**遗忘**）。不用"多数票"是因为多数票会把**攻击姿势**这种少数帧状态剔出去，于是动作撑开的边缘变成残差、又被 J4 当成"出现过的"报出来 —— 而它恰好出现在干员格上，也就是敌人最可能出现的地方。

## 7 兜底与已知破口

**静止的敌人会消失，这是想要的效果**（用户 10-18）。两条兜底都不依赖画面：

| 兜底 | 覆盖什么 | 出处 |
| --- | --- | --- |
| **血条**（J7） | 已经在挨打的（被阻挡的必定在挨打） | [敌方单位.md](敌方单位.md) 那条链 |
| **首轮探索的停留点** | 按设计会停一段的 | [路线](../资产生成器/地形与关卡资产/路线.md) §1.1 |

**已知破口（记着，先不治）**：

- **单格大小、不透明、还持续存在**的特效：四格表会把它判成"纯色 ⇒ 不报"，但如果它带纹理，就会落进"报"那一格；
- **纯色单位**（黑雾类、极简形体）：落第四格，会被当成特效漏掉；
- **雪花 / 粒子**：纹理高、相关低，会落进"报"那一格 —— 靠第 5 步第 3 条（成群散点）先剔掉；
- **敌人被特效间歇遮挡**：**不考虑**（用户 10-18）。理由：特效逐帧都在变，两帧很难"变得足够像"以至于把被盖住的敌人重新露出来；而且就算露出来，它也已经进了 J5 的交集，结果与这条无关，两条兜底不受影响。

## 8 已否掉的做法

| 被否的 | 理由 |
| --- | --- |
| 账 + 画面合成给答案 | 账算不准，工作量不划算 |
| 整格划掉我方干员格 | 干员格上恰恰可能有敌人（阻挡） |
| 攻击范围当特效范围 | 时机、形状、实际大小都未知 |
| 只在我们的动作时更新背景（一次性写入） | 部署到有敌人的格会把敌人永久烘进背景 |
| 长学习期 | 会学到脏东西；技能才 20 秒，学完就结束了 |
| 用技能时刻做豁免 | 特效跨干员影响（一个干员的特效会盖到别人），范围未知，豁免不了具体格 |
| 必要条件求交 / 求和 / 投票 | 判据有主次，不能压成集合运算 |
| 用尺度（跨几格）剔特效 | 怪海本身就跨多格 |
| 空地格放宽持续性 | 朝哪个方向放宽未知；属其他层 |
| 受击闪白 | 游戏里没有，且各敌人不统一 |
| 几何判据（阻挡位移 / 最小·最大距离） | 只对部分敌人生效，情况太复杂 |
| 单帧量干员占位 | 干员有动作和特效，一帧不够 |

## 9 尚未定

- **"看不出"在条件检测里算不算触发**：暂停是低代价动作，可能该算"保守触发"；但不可回退的动作要反过来 —— 这条等方案整体定完再定（用户 10-18）；
- **面积门的阈值**：要先量最小那一档怪的实际面积，再定在它下面并留余量；
- **干员格要不要单独提高门槛**：动作残差漏在占位外时，是扩占位（会吃掉贴着干员站的敌人）还是提门槛（干员格更迟钝），是拿漏换误报，等风险排序；
- **全部阈值与窗口长度**：一两帧、k 帧、纹理门、相关门，一条都没测；
- **四格表的证据可信度**：白地板、雪地、粒子特效、怪海、纯色怪这五类各测一遍，看它们实际落在哪一格 —— 这是四格表能不能当核心的唯一证据。
