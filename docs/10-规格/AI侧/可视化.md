对应代码：`dsh/plugin/`（**未建**）。它是 DSH Web GUI 的**客户端插件**——**纯消费者**：只从引擎读数据画图，不参与业务逻辑（[DSH平台事实](../../30-专题/DSH平台事实.md) §七）。

**这是 [AI 侧](README.md) 的正文之一**——概览、判断标准与红线见 [README.md](README.md)。

## 它是给谁看的

**给人看 AI 在干什么。**

| | 本文件 | [首轮探索](../首轮探索/README.md) §4 |
| --- | --- | --- |
| 是什么 | **只读的视图** | **可写的编辑器** |
| 谁用 | 看 AI 打的人 | 做资产的人 |
| 什么时候 | AI 排轴时 | 资产还没做出来时 |
| 住在哪 | DSH Web GUI 里 | 本机独立进程，不接 AI |

**两者不能合成一个**：合成等于让 DSH 会话去做资产编辑，正好把"唯一给人用的东西"塞回在线链路。

## 1 第一版：渲染工具调用，不开面板

用 `tool.call.toolview` 这个 **keyed、追加式**座位，把图直接画进对话流里。理由在[座位表](../../30-专题/DSH平台事实.md) §六：那个座位已占的 key 里**一个 `mcp__*` 都没有**，全是空位；而且图**自己出现在对话流里**，用户不需要去开面板。

## 2 只渲染三个算子

| 算子 | 画什么 |
| --- | --- |
| `看快照` | 六块 → 一张图（地形字符图 + 格网 + 干员 / 敌人位置 + 页眉的存疑清单） |
| `看轴` | 动作表 → 一条时间轴 |
| `继续到` | 一段 → 进度条 + **结束原因**（命中 / 上限 / 画面变了 / 中止） |

**其余十一个读算子不渲染**——它们的返回是表，看表比看图清楚。

## 3 一份渲染、两个壳

格网 · 地形着色 · 路线折线那套画法，**首轮探索是编辑器、这里是视图**：共享**渲染代码**，不共享 UI。

## 4 两条纪律

- **数据必须已经在返回值里**：插件是纯消费者，**不为 UI 单开通道**。缺什么说明**返回值缺什么**——那是接口层的缺口，不是插件的活。
- **渲染失败必须局部化**：客户端插件接口"会无预警变化"（[DSH平台事实](../../30-专题/DSH平台事实.md) §七），所以图不出现时**会话照跑**。这不是容错设计，是那个座位本身的性质。
