# skill 的设计要求

> 状态：讨论中 ｜ **已立**：使用手册 · genre 判据 · 分份四条 · 候选五份 · 可检验形式

**这是 [AI 侧](README.md) 的正文之一**——概览、判断标准与红线见 [README.md](README.md)。

**本文只写要求**：skill 的**文本**不在这里（同 [代码结构](../代码结构.md) 与代码的关系）。产物落 [dsh/skills/](../../../dsh/skills/README.md)。

## 它是使用手册，不是行为约束

手册回答"这东西怎么用、它是什么性质"，**不回答"你该自律成什么样"**。

## 1 genre 判据：能改写成「系统的性质」才写

| 能 → 写 | 不能 → 不写 |
| --- | --- |
| 「**没有回滚**，要回头只能改轴重跑」 | 「不要要求回到第 N 帧」 |
| 「`看原帧` 只留**被识别过的那几帧**，之前的像素不存在」 | 「不许把看原帧当常规路径」 |
| 「工具**不会"尽力执行"**，只报三态」 | 「不静默跳过读不到的东西」 |
| 「不变量**每轮自动对账**，违反进存疑清单」 | 「工具报违反时才复查」 |

**右列全是自律要求，一律不写。** 于是 [README](README.md) §1③④ / §2 / §3 里有**一半内容不进手册**——它们留在那里当规格，去向见[那份文件的「尚未定」](README.md)。

## 2 分份：四条

| # | 要求 |
| --- | --- |
| **M1** | **一份 = 一个作业环节**——AI 在某一刻要**一起**用到的东西。判据：这两块会不会在同一次调用前一起用？ |
| **M2** | **不跨份依赖内容**：只读了 A 没读 B，也不能因此出错。允许**点名**（"要用 `注册字段` 时加载 `ark-fields`"），不允许**依赖** |
| **M3** | **有一份是入口**：这是什么 + 一次往返 + **其余各份的一句话索引** |
| **M4** | **description 说清"什么时候加载我"**——它是常驻的唯一发现面 |

## 3 候选分份：五份（名字与边界先占位）

| skill | 覆盖哪个环节 | 什么时候加载 |
| --- | --- | --- |
| `ark-start` | 这是什么 · 一次往返 · 责任边界 · **其余四份的索引** | 接手一个战局之前 |
| `ark-read` | 快照六块 · 三个轴（三态 / 形态 / 置信度）· 存疑清单 · 成分表 · 观测迹是稀疏的 · 读类六个算子怎么选 · `查资料` 的两类来源 | 要看战场 / 要查事实 |
| `ark-plan` | 轴是什么 · 动词表 · 帧号语义 · **朝向必填** · 动作最小间隔 · 排动作五个算子 · `看轴` / `看记录` | 要写或改计划 |
| `ark-run` | 暂停条件的文法 · 时限必填 · 三值 · 两段式 · `继续到` 的四类结束 · 生效反馈 | 要推进 |
| `ark-fields` | 三档（一档 / 注册字段 / 工具固定提供）· `注册字段` · 编排 | 开工前过效果 / 遇到不认识的字段 |

**M1 那条判据是定的，这五刀不是**——`查资料` 该待在 `ark-read` 还是自己一份、`ark-fields` 算不算一个"环节"，实现时再收。

## 4 每份里该有什么

- 这个环节**能用哪些工具**、**各自什么时候用**——是"选择"，不是"定义"；
- 这个环节**我会看到什么**（返回的形状）；
- 这个环节**系统的性质**——哪些做不到、哪些自动发生。

**不写**：参数规则（归工具描述）· 静态事实（归 `查资料`）· 阈值 / 默认值 / 帧数 / 倍率（未实测，写了就是假精度）· **"详见 docs/…"**。

**最后一条不是洁癖**：[bundle](../../../dsh/bundle/cordis.patch.yml) 的 `plugins` 里一个 `dsh-tool-*` 都没挂（[D-全局-08](../../20-决策记录/全局.md)），AI 只有 persona + MCP + skill 三条通道，**`docs/` 对它不可见**。而且就算可见也不该读——生成物格式会变、内容没有校验，直读就是把假事实从字段级漏到文件级（[算子清单](../接口层/算子清单.md) §2）。

## 5 可检验形式

| # | 怎么验 |
| --- | --- |
| **V1** | **自足**：每份里"见 / 详见"后面只能是**工具名或本份的章节** |
| **V2** | **无副本**：出现的每个字段名 / 方法名 / 算子名，**必须也能从 `查资料` 拿到** |
| **V3** | **genre**：逐句问"这是系统的性质，还是对 AI 的要求"——纯要求删掉 |
| **V4** | **最硬的一条**：空会话**只读 `ark-start`**，能不能自己走出第一步 |

## 尚未定

- **五份的名字与边界**（§3）；
- **每份的长度上限**——M2 守得住的话每份自然会短，先不设数；
- **`ark-*` 这个前缀**要不要换。
