## 0. AI 的输出只有两样

| 输出 | 落到哪 |
| --- | --- |
| **轴**（改哪几处） | 排动作那五个算子（`部署` / `撤退` / `开技能` / `关技能` / `删动作`） |
| **暂停条件**（跑到哪） | `继续到` 的参数 |

其余全是读。**归因结论不进机器**——它是给人看的判断，不是要执行的指令。

这条值得单独写，因为它是"让 AI 专注攻略构思"的**可检验形式**：输出面越窄，上下文越省，工具与 AI 的分界线越不容易糊掉。**任何新增的写入口都要先回答"凭什么它不能被纸面推演覆盖"。**

## 1. 一轮里 AI 按什么标准做

循环的形状在《概念设计共识》§6，算子怎么串起来在[算子清单](../接口层/算子清单.md) §1——**都不在这里重复**。这里只写每一步的**判断标准**。

### ① 读记录：读出三样，别的去查数据库

出怪顺序 · 费用曲线 · 首次接敌时刻——《概念设计共识》§6 已点名这三样是记录的副产品。它们的共同点是**数据库给不出**：数据库说"这一关有哪些敌人、多少费"，说不出"这一局实际第几帧出现"。

于是判据是：**凡能在数据库里查到的，不要在记录里找；凡只能在记录里得到的，必须读出来。** 找错地方会让 AI 在读记录上烧掉大量上下文，而那本该是几次 `查资料`。

### ② 纸面推演：把"第几秒"折成帧号

轴上的锚点是**逻辑帧**，不是秒（[时序层](../时序层.md) §2）。AI 手上是游戏内的时间关系（"回费到 20 点要多久"），折成帧号就是 **×30**（[时间基](../../30-专题/时间基.md) §2）；其中"多久"用的是前提头里的**标称**速率。

**但标称只是计划值，不是保证**——余额有十几种来源（[时间基](../../30-专题/时间基.md) §3.1），推演算出来的时刻**必须由 `继续到` 的条件与必填时限兜底**，不许当成"到那时一定够钱"。

**这一步是 AI 最该花 token 的地方。** 它替代的是一次实机试错，而实机比 token 贵得多。

### ③ 改轴：默认只改有问题的那些操作

这是最初诉求的原话：**反复探索同一条轴时，AI 应当能直接审批已经做过的操作，只优化那些有问题的操作**，而不是每轮重读重写一遍。

所以默认姿态是**沿轴前进 + 只改有问题的点**。判据是"有没有证据说它有问题"：

| 证据 | 从哪来 |
| --- | --- |
| 动作**未确认**生效 | 轴上的生效反馈三态（[执行与失败](../接口层/执行与失败.md) §3） |
| 不变量 I1–I4 被违反 | 快照页眉的[存疑清单](../状态层/快照.md) |
| 字段降级 / 通道冲突 | 同上 |
| 时间不可信 | 段的结束原因 |
| 与纸面推演不符 | 自己算的预期 vs 快照的实际 |

**没有证据就不改。** 这是"不做排列组合遍历"（《概念设计共识》§6）在行为层面的样子——**它约束的不是改不改，是"凭什么改"。**

### ④ 归因：只定证据从哪来（**判据不做**）

"一次失败是概率导致的还是必然的"——**判据明确推迟，不做一刀切**（[开题状态](../../00-总览/开题状态.md) §4）。这里不定判据，只定一件事：

**归因的证据来自 §③ 那张表，不来自重复实验。** §6 已排除"稳定失败再改轴"这条策略，理由是它把归因变成了测概率——而 AI 应当有能力读证据。

## 2. 红线

| AI 不许做 | 为什么 |
| --- | --- |
| 把"看原帧"当常规路径 | 它是逃生舱；用它的频率是抽象层的缺陷信号，不是工作方式（[算子清单](../接口层/算子清单.md) §4） |
| 要求"回到第 N 帧重来" | 基线第 11 条已排除；要回头就是改轴重跑 |
| 靠重复实验测概率 / 玩排列组合 | §6 已排除 |
| 自己发明字段名 | 字段名就是接口名，改名等于改接口；自定义字段由工具按效果键生成（[状态层](../状态层/README.md) G3） |
| 把"置信度低"当成"再确认一遍"的理由 | 见 §3 |
| 静默跳过读不到的东西 | 读不到要按三态上报，不能当它不存在 |

**"必须拒绝执行"这一侧不在 AI 手上**：前提不吻合、版本不认识、画面不是战斗界面，一律由工具**整段拒绝**（[执行与失败](../接口层/执行与失败.md) §4），AI 没有"我确认一下就能跑"的余地。

## 3. 过度验证：不给验证留预算，把校验搬进工具

《概念设计共识》§5.3 已定：**AI 会自发核对注入给它的抽象，所以不需要设计促进验证的机制；需要约束的是过度验证烧 token。** 这一节把那条约束定下来。

**结论：不给验证留预算——因为没有为验证单开的通道。** 三件事各自消掉了一类"再确认一遍"的动机：

1. **每次采样自带置信度**（[状态层](../状态层/README.md) G1）。AI 不需要重采样来判断一次读数可不可信——它需要的是**在推演里按置信度加权**。
2. **不变量由工具每片对账并主动上报**（[执行与失败](../接口层/执行与失败.md) §4）。跨片的矛盾不用 AI 自己记着去核。
3. **降级与冲突有页眉汇总**（[快照](../状态层/快照.md)）。不用 AI 逐个字段翻。

于是 AI 的复查只剩**一个触发条件：工具报了违反**。不是在"我觉得可能不对"上复查，是在**工具说不对**上复查。

**这条约束的可检验形式**：一次往返里，除了 AI 自己要读的字段，**不应出现第二个读操作**。出现了就说明上面三条里有一条没生效——那是引擎的缺陷，不是 AI 需要被提醒。

## 4. 人机分工

| 事 | 谁 | 依据 |
| --- | --- | --- |
| 合约词条 | **人** | 用户裁定；它改初始费 / 回费速率 / 可部署格，是前提头的一部分（[时序层](../时序层.md) §3） |
| 配队 | 可自定，也可人指定 | 《概念设计共识》§2.3 |
| **首轮探索** | **人**，经工具记录 | 用户裁定；没有记录器就没有起点（[开题状态](../../00-总览/开题状态.md) C2） |
| 战斗之内的决策与操作 | **AI** | 《概念设计共识》§3 责任边界 |
| 重跑 / 选关 / 重进 | **人** | A5 已排除：任何导航都会把成本结构拖回 MAA 那一套 |
| 结算画面 | 工具顺带识别，**不导航** | [控制层](../控制层/结束.md) |

**成功判据是通关一次**（用户裁定），不是"轴好看"或"容错高"——§9 已排除以容错余量为优化目标。

## 5. 落到 DSH 上是什么

- **人设**：`dsh/bundle/cordis.patch.yml` 里已有前缀。装上工具面之后再改，现在那句"不要凭记忆推断"仍然对。
- **skill**：**使用手册**——这套东西怎么用、一次作业怎么走、每个环节会看到什么。**设计要求在 [skill.md](skill.md)**，产物落 [dsh/skills/](../../../dsh/skills/README.md)。本目录 §0～§4 是它的素材。
- **可视化**：DSH Web GUI 的客户端插件，**纯消费者**——见[可视化.md](可视化.md)。
- **字段目录不写进 skill**：它由 `查资料` 从引擎取（[算子清单](../接口层/算子清单.md) §2）。写进 skill 就会**过期**——其中一部分是本局才有的（要才取名单、已注册字段），权威在引擎。
- **进度不进提示词**：会话压缩后 AI 靠 `看战局` 接回来，而不是靠提示词里那份会过期的复述。
