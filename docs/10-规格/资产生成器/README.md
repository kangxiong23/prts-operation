# 资产生成器

> 状态：讨论中 ｜ 五样产物已列；**特征库流水线已立**，其余三份规格各有各的现状

对应代码：`src/ark/offline/assets_gen/`。

## 这份文件负责什么

从官方数据、界面截图与人工录入，生成五样东西。各自另有一份规格：

| 产物 | 规格 | 落到哪 | 进版本库 |
| --- | --- | --- | --- |
| 游戏数据库 | [游戏数据库.md](游戏数据库.md) | `assets/gamedata/` | 不进 |
| 地形与路线 | [地形与关卡资产/](地形与关卡资产/) | `assets/terrain/` | 进 |
| 特征库 | [特征库.md](特征库.md) | `assets/features/` | 进 |
| **干净关卡背景帧** | [背景帧.md](背景帧.md) | `assets/backgrounds/` | 进 |
| **卡面与指纹** | [卡面与指纹.md](卡面与指纹.md) | `assets/roster/` | 进 |

**「地形与路线」是一份目录**：路线逐关、与地形同验收，所以和地形放一起——概览在[地形与关卡资产/](地形与关卡资产/)，路线那一份是[路线.md](地形与关卡资产/路线.md)。**路线本身又分「形状」与「出怪记录」两层**，两层随不同的东西失效（[路线.md](地形与关卡资产/路线.md) §1）。

**人工创作那一半有一个专门的人机入口**：[首轮探索](../首轮探索/README.md)——它同时就是[开题状态](../../00-总览/开题状态.md) C2 要的那个**记录器**。它是项目里**唯一给人用的东西**，不接 AI、不驱动游戏。

**注意有两处名单的交叉**：**特征库**已经有自己的规格了（[特征库.md](特征库.md)）——这个目录**本来就是靠这个机制长大的**；而 **UI 布局常量**（ROI 坐标表）**不在这里**：它的值在设计代码时定下来（用户裁定），不单独出一份资产。

## 标注的大头仍然是免费的，但要说准

对比"要人工标一堆东西"的直觉：

- **我方每次部署动作本身就是一次卡位标注**（点了第 N 张卡 = 那一刻第 N 张卡是它）——**但"第几张卡是谁"推不出来**（备战席不按编队顺序，且同费用并列），所以**开局第一眼那次点名跑不掉**，见[卡面与指纹.md](卡面与指纹.md) §1；
- **路线资产（含出怪）给出敌人的类型标签**——**但给的只是候选集**，个体配对要靠**那条格序列推算出来的位置**去对，见[特征库.md](特征库.md) §2；
- **真正需要人工的只有界面型资产**，而它的规模只随「UI 与识别点种类数」增长，**不随关卡数增长**。**唯一的例外是效果外观**——它是游戏定义的开放集，只能**按需长**（[注册字段](../状态层/注册字段.md) 被拒的那条记录就是它的需求来源）。

## 五样资产，四种来源

| 资产 | 来源 | 怎么维护 |
| --- | --- | --- |
| 游戏数据库 | 官方数据 + 界面截图，**派生** | 生成器重跑 |
| 特征库 | 截图采样，**派生** | 生成器重跑 |
| **干净关卡背景帧** | **实机采集**——干净跑一局、开局抓一帧（**慢放视图另抓一帧**，见下） | 按版本重抓 |
| 地形与路线 | **人工创作** | **边打边画**（[首轮探索](../首轮探索/README.md)）：工具只搬不判断 |
| **卡面与指纹** | **实机采集 + 人工录入** | `启动` 顺手截编队页，人补注册；按"遇到过就留"累积 |

派生那两样，生成器要能**全量重跑并给出可比较的结果**，否则没人敢动它。

**干净关卡背景帧**是一种单独的来源：它**没法"生成"**，只能**跑一局抓一帧**。好处是**首轮探索本来就要人跑一次**（[开题状态](../../00-总览/开题状态.md) C2），所以几乎是白拿的。打戳：**关卡 × 相机参数（视图）× 游戏版本 × 渲染设置**——它只在"同一关、同一视图、同一版本、同一设置"下能当背景用（[视觉层/敌方单位.md](../视觉层/敌方单位.md)）。**"视图"这一维不能省**：识别多数发生在**慢放 + 详情面板**下，那时几何和常速不一样（[投影](地形与关卡资产/投影.md) §3）。

**卡面与指纹**与别的四样都不同：它记的是**这个账号上的干员**——长什么样（卡面）与练到什么程度（指纹），不是游戏本身的数据。**所以它不能进 `assets/gamedata/`**——那一份按 [D-全局-02](../../20-决策记录/全局.md) 是不进版本库的，而这里有人一条条填出来的部分，**丢了就要重填**。轴的「练度指纹」只存**标识**，值由工具从这里取（[时序层](../时序层.md) §3）；**卡面与指纹是两个键**，见[卡面与指纹.md](卡面与指纹.md) §0。

**地形不同**：它的语义来自人的判断，不来自任何数据源。所以这里没有"重跑"，只有"改图 → 校验 → 验收"。理由见 [D-全局-09](../../20-决策记录/全局.md)。
