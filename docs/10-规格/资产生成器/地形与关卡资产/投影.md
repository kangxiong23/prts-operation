# 投影

> 状态：讨论中 ｜ 两套参数已定；**平移量待实测**

**「地形与关卡资产」的正文之一**——概览、四个文件与词条覆盖的三类见 [README.md](README.md)。

每个关卡一份「格坐标 → 像素」的映射，屏幕位置由它算出，**不每帧从画面里找格子**。它宿主在 `.json` 的 `projection` 里。

## 1. 不止一套

- **常态与慢放是两套参数**——**进入慢放**（点干员或点备战席卡片）**时**游戏会把地图往右倾斜并位移，几何变了。**用户确认：平移只发生在切视图的时候，常速下不动**，具体数值待测；
- 所以"一局之内不变"这句话**只对同一个视图内成立**：**切视图 = 换一套参数**，不是"参数随时间漂移"。**切换时间态时同步切换投影。**

## 2. 对不上就报错

**对不上就拒绝执行**——这是"前提头校验"那条规矩用在几何上；但对不上时**先问"是不是视图没切"，再问"是不是数据错"**。

这条提醒有出处：[MAA借鉴清单](../../../50-外部借鉴/MAA借鉴清单.md) §9.6 那句"几何对不上不一定是数据错，也可能是关卡特例"，到我们这里是"**也可能是我们自己忘了切视图**"。

## 3. 连带：背景帧也按视图各一份

干净关卡背景帧**按视图各备一份**——识别多数发生在**慢放 + 详情面板**下（[控制层/识别时机](../../控制层/识别时机.md) §4 的"抓帧在暂停前"），那时用的是慢放那一套几何，拿常速的背景帧去减会整片对不上。

背景帧本身见 [../背景帧.md](../背景帧.md)。

## 4. 详见

[地形模型](../../../30-专题/地形模型.md) §10——那里还记着"遮挡是几何问题，不用识别"（详情面板是已知矩形，与目标的投影一相交就知道挡没挡住）。

## 尚未定

- **慢放的平移量是常量还是随"点了哪个干员"变**：面板位置固定，所以**倾向常量**，但要实测（与[../背景帧.md](../背景帧.md) 的「尚未定」是同一条）；
- **投影类型要不要自带"常速 / 慢放"的标识**，还是调用方各持一套参数（[契约层](../../契约层/README.md) 的「尚未定」里也记着这条）。
