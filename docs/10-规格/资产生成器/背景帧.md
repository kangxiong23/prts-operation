# 干净关卡背景帧

> 状态：讨论中 ｜ 已立；**按视图各一份**与慢放平移量待实测

落到 `assets/backgrounds/`，**进版本库**（见 [README](README.md)、[D-全局-10](../../20-决策记录/全局.md)）。它是**五样产物之一**，也是唯一**没法"生成"**的那一样。

## 1. 它是什么

**一张该关卡、该视图下的干净战场底图**，用途只有一个：**差分**。

```
单位掩码 = |当前帧 − 干净关卡帧| > 阈值
```

- 它**不识别地形语义**，只做减法 → 与 [D-全局-09](../../20-决策记录/全局.md) 排除的"从像素检测地形"**不冲突**；
- 美术换皮不伤它（它跟着版本一起换）；
- 使用者是[视觉层/敌方单位](../视觉层/敌方单位.md) 的第 2 步，那里管**怎么用**；本文件只管**它从哪来、什么时候作废**。

## 2. 为什么不能用"本局的开局帧"

部分合约词条会让**初生敌**（"初始存在xx怪"）开局就在场上——它们在开局帧里，于是"看上去没变化" → **有漏检风险**。用干净帧，初生敌照常出现在差分里。

**它们出现在非门格上**（用户确认）——所以它们**不污染门格**，这正是[门检测点](../首轮探索/出怪与路线.md) §1 能拿本局开局帧当参考的原因。两件事的干净范围不同。

## 3. 从哪来：实机采集，一关两帧

**它没法"生成"，只能跑一局抓一帧。**

| | |
| --- | --- |
| 谁 | **人**——首轮探索本来就要跑一次（[开题状态](../../00-总览/开题状态.md) C2），所以几乎是白拿的 |
| 怎么 | **零词条合约开局无敌人**（用户确认）→ **开局那一帧就是干净帧**；万一某关有初始敌人，由人**自己造一个干净环境**，以那一帧为准 |
| 何时 | 与地形、路线同一个时机（首轮探索） |

**只有无词条那一局的开局帧才算数**（用户确认）：带词条的局里，词条会让**初生敌**开局就在场上。所以首轮探索**至少要两局**——一局无词条（背景帧 + 基础出现帧）、若干局带词条（该组合的出现帧覆盖），见[首轮探索/出怪与路线](../首轮探索/出怪与路线.md) §5。

**按视图各一份（用户确认）**：相机**只在切视图的那一刻**平移，所以同一个视图内不用配准；**但视图有两套**（常速 / 慢放 + 详情面板），而识别多数发生在**慢放**下（[控制层/识别时机](../控制层/识别时机.md) §4 的"抓帧在暂停前"）。拿常速那一帧去减慢放下的画面会**整片对不上**。

**所以一关是两帧**：常速一帧、慢放一帧。慢放那一帧要**连详情面板一起抓**——面板本来就是那一刻画面的一部分（[投影](地形与关卡资产/投影.md) §3）。

## 4. 打戳

**关卡 × 相机参数（视图）× 游戏版本 × 渲染设置**

只在"同一关、**同一视图**、同一版本、同一设置"下能当背景用（[视觉层/敌方单位](../视觉层/敌方单位.md)）。

## 5. "干净"是机制保证的，不需要验收

**它不是一个要验的性质，是一条游戏机制**（用户确认）：

- **零词条合约开局必定没有敌人** → **开局那一帧必定是干净帧**。已知的合约**没有一次违反过这条**；
- 万一某关**有初始敌人**：由人**自己造一个干净环境**，**以那一帧为准**——也就是说"干净帧"的定义是"**由人挑定的那一帧**"，不是死板的"开局那一帧"。

**所以这里没有离线验收这一环**——不像[特征库](特征库.md) 那样要出一份可 diff 的清单。**抓帧的时机本身就是那条保证。**

**但运行期自检必须留着，它测的是另一件事**：拿**本该静止的区域**（地图边缘装饰）看差分是否近零——**不近零就判定失配、整块放弃**。它测的不是"这一帧干不干净"，而是"**它和当前画面还是不是同一个视图 / 同一个版本 / 同一个设置**"。判据在[视觉层/敌方单位](../视觉层/敌方单位.md) 第 2 步。

**两件事别混**：干净 = 抓帧那一刻的**事实**；匹配 = 用的时候的**校验**。

## 6. 战场 ROI 与它是一对

差分**只在战场区域做**（HUD / 备战席排除——它们每帧都在变）。而慢放那一帧还要多问一句：**详情面板算进背景、还是排除出 ROI？**

- **算进背景** → 面板上的数字（生命 `4227/4227`、充能读数）每帧在变，**那一块会一直假阳性**；
- **排除出 ROI** → 干净，但**损失战场最左约四分之一**（[视觉层/技能详情通道](../视觉层/技能详情通道.md) §7.4）。

**倾向排除**——损失的那一块**切回常速就能看**（[控制层/时间态](../控制层/时间态.md)）。这条还没定，见下。

## 7. 回流

**差分自检失败就是难例**（[采集与验收](../采集与验收/README.md) 的触发之一）——它落盘的原帧同时就是"这一帧背景帧**失配**了"的证据：要么**视图没切**，要么版本 / 设置变了，**该重抓**。

## 尚未定

- **慢放的平移量是常量还是随"点了哪个干员"变**：面板位置固定，所以**倾向常量**，但要实测；
- **详情面板算进背景还是排除出 ROI**（§6）；
- **战场区域的边界**（HUD / 备战席 / 详情面板排除掉之后剩什么）——这条挂在[视觉层/敌方单位](../视觉层/敌方单位.md) 的「尚未定」里。
