# 编队页名字那一读

> 状态：讨论中 ｜ 版面、取区、验收线**已实测并有一次真机读数**；**两套次序的映射与一局产物的落点待定**（下一单的头号问题）

编队页卡下缘印着**名字**（白字压在深色横带上，右对齐），而印的是**皮肤名** —— 所以名字与立绘是同一件事（[D-全局-36](../../20-决策记录/全局.md)）。这一份写**怎么把它读出来**：版面、取区、判决，以及**那一次线上调用的通道**。资产落点见[卡面与指纹](卡面与指纹.md)；判决对的是**全量闭集** `assets/roster/names.json`（431 名，含皮肤名）。

**视觉层不走大模型**；这里走的是**通用 OCR 的那一个端点**（[D-全局-45](../../20-决策记录/全局.md)），**一局一次**，结果落盘 —— **识别链本身仍然离线**：仓里存着拼图与接口原文，重放时网一个字都不用动。

## 1 版面：十格竖排，一行一格

| | 值 | 怎么来的 |
| --- | --- | --- |
| 名字墨迹行（上行 / 下行） | `577..607` / `1081..1112` | 原生坐标实测；**608 那一行整行是亮背景**，不许进取区 |
| 名字框 | `[卡左缘 + 9, 卡左缘 + 208]`，宽 **200** | 两个最长的名字左端都落在 `+9`；**超长名字由游戏缩字塞进这 200**（用户给的事实） |
| 取区 | `[卡左缘, 卡左缘 + 214)` × 名字行 | 卡左缘 = `470 + 271k` |
| 格与行间 | 格 214×44、行间 **25 px**；上 6 行 + 名字行 + 下 6 行 | 图片尺度不是约束（最长边 4096、体积 4M 都宽） |
| 底色 | **四边一律深色，不许白边** | 见 §2 |

**四条边界都必须落在深色上**（不许有一条亮线横穿取区）—— 这条比上面那些数字重要，量取区时按它自查。

**取区左端为什么不越过卡左缘**：`卡左缘 − 1` 那一列是左邻卡右缘的一块亮像素（十个格都有；最右一列在上行 0/1/2 与下行 5/6/7 上亮到 255）。而名字框左边还剩 9 px，所以取区贴到卡左缘为止，两边都不碰。再往左 1 px 就脏，再往右就切名字 —— 这个位置是**唯一**的。

**右上「助战」那一格不在这一读里**：它印的是「助战干员 / SUPPORT UNIT」这个标签，**不是干员名**，
所以 OCR 读不到名字、也不该去读 —— 库里的名字是**固定占位名**，理由与那三条规矩见
[卡面与指纹](卡面与指纹.md) §右上那一格「助战干员」。拼图按**真实卡列**排行：别把那一格当第 7 列
拼进去，否则那条标签带会跟着进拼图、变成一个假的「词」。

## 2 为什么竖排：**白边会把相邻的词粘起来**

**实测**：旧横排每格 262×66（**含 24 px 白边**），名字右端顶在取区右边界 ⇒ 每个名字右边直接粘着一条白；而**下一个名字的左端离那条白边只有 `214 − 名字宽` px** —— 短名字 74…148 px（分得开），两个长名字只剩 **14** ⇒ 中文 OCR 把上行 2/3/4 三格并成一个词，**10 格只回 8 个词**。

⇒ **元凶是白边，不是横排**（这一点当时认错过，以实测为准）。竖排让任何名字**横向没有邻居**，加上深色边，两个方向都粘不起来。

**实测（竖排那一版）**：接口回 **10 个词、一格一词**；相邻词框的空档 **23–28 px**（＝ 25 px 深色行间够用），两个长名字的框左右都顶到拼图边缘（`x = 0..213`）**仍然各自成词**。

**取区左端改成卡左缘之前的自证**：十个格里取区左边界那一列全是深（51–53），而它的左邻那一列有六个格是亮的。

## 3 判决：三档 + 一条验收线

归一化（间隔号 / 全角 / 空白 / 大小写）→ **精确命中**闭集 ⇒ 采用；否则取**编辑距离 ≤ 1** 的候选：**恰好一个** ⇒ 采用并标「**改过**」；**0 个或 ≥2 个** ⇒ **未知**。**合词绝不许切成拼接的名字。**

**验收线：未知 0 且 改过 ≤ 1 且 错 0**（`改过` 不算错，但也不许拿它把错吞掉 —— 它单独报数）。

**已知的字形混淆**：`白面鸮` 被稳定读成 `白面号`（两单都这样）；距离 1 的候选唯一，所以人还是认得出来。

## 4 两块石头：拼图与响应都留仓

`tests/帧样本/编队页名字竖排/`：**喂进去的那张拼图** ＋ **接口的原始响应文本**，两样都在版本库里，各自的 RAW sha256 与字节数记在 `index.json` 里。

**只留哈希证不了「当年发出去的是这张」，只留图证不了「接口回了什么」** —— 两样都留才叫可重放（旧横排那一版也是这么留的，它现在是「合词」那件事实的证据）。

**完整重放要原图**：拼图是从 `screenshots/run-04/编队界面.png` 拼出来的，而**原图不进版本库**（3 MB）。所以在没有那台机器的场合，能重放的是**判决链**（`parse_words` → `assign_words` → `decide`，喂 `响应.json` 的文本），**不是**「再拼一遍」；拼图本身的哈希与「两份真值逐字一致」由 `tests/spec/formation_names_spec.py` 盯着。

## 5 次序：**两套次序的映射还没定**（欠账）

- 这一读出来的 slot 次序 = **拼图的行序**（上行左→右，再下行左→右）—— 接口给的十个词框 `y` 单调递增，所以这个次序**没有歧义**。
- 而库那一侧（[卡面与指纹](卡面与指纹.md)）吃的是 **roster 卡位序：0 = 最右那张**。

**这两套之间的映射现在谁也没写下来。** 它是会**静默把名字贴错人**的那种坑 —— 所以它是下一单（库落盘 / 进引擎）的**头号问题**。在那之前，一局产物里的 slot 只按**行序**读。

**一局产物的家（已定）**：它是**建库那一步的凭据**，不是资产 ⇒ 住 `data/roster_state/`（运行期状态、**不进版本库**）；`assets/roster/` 只放**资产** —— 全量闭集 `names.json` ＋ **库** `faces.json` ＋ `faces/<id>.png`。夹具里那份样本（`<局指纹>.json`，文件名**原样不改**）只是样本。

**库（`assets/roster/faces.json`）**：按干员**累积**，一块 = 编队页那张卡的**立绘**（`214 × 480`，无损 PNG）。存整块是照判据来的 —— 比对时要在这一块里**滑着找**备战席那个 `100×100` 的窄框（[视觉层/备战席点名](../视觉层/备战席点名.md) §判据的形状）。**代价照实说**：10 块 ≈ **1.57 MB**，全量 418 位外推 ≈ 65 MB ⇒ 这一版**只落遇到过的**；换更小的存法是**另一单**，换之前要先有一条「比对结果不变」的网。

**键的那个洞**：键是「干员 × 精英化 × 皮肤」（[卡面与指纹](卡面与指纹.md) §0），而那一读**只给名字** ⇒ **精英化这一维填不出来**，`id` 暂时按**卡面像素**算（内容寻址：同一套立绘第二次遇到是同一个 id；同一个名字两套立绘就是两条 id）。等精英化能读了再加进键里。

**引擎侧的注释不点名离线那一侧的具体类**：那边给库的实现换了名字（`EmptyAssetPort` → `RosterAssetPort`），设备层的注释里一句旧类名就跟着烂了。说"离线那一侧那个实现"就够了 —— 点了名字就是把两层在文字上也焊住。

## 6 线上通道那一个端点

**默认先按默认安全级打**；握手失败、**且原因是握手签名那一类**（`SSL: WRONG_SIGNATURE_TYPE`）时，才对**那一次连接**降级重试**一次**（`DEFAULT@SECLEVEL=0`），并把**降级原因原文与用时记进账**。**不是无条件降级**；两次都**照验证书、都加密**，**任何情况下不许明文 http**。

**为什么会有这一条**：讯飞那个边缘主机在握手里用 **SHA-1 签名**，而 OpenSSL 3 默认安全级不接受它 —— 纯 RSA 套件（握手过程里没有那句签名）在默认级别就通，凡是要 ECDHE 的只有安全级 0 才通；而且它**是颠的**（一窗通、一窗三十多次全断），取决于哪个边缘节点接的。**代价照实说**：安全级 0 放宽的**不止**握手签名（链上的 SHA-1 签名、最小密钥长度一起放宽），所以它是有代价的退路，不是默认。

**凭据只从环境变量读。** 这条链要求变量**在主机进程启动前**就在环境里，或**由调用方显式注入** —— 机器域环境变量**不会**自动进一个已经起好的进程的环境块（那次真调用就是这么搬进去的）。凭据缺失的报错要把这层说出来。

**沙箱事实（不是网络事实）**：DSH 的沙箱里 `curl.exe` 走 Schannel，对**所有** https 站点都拿不到凭据（`SEC_E_NO_CREDENTIALS`，连百度也一样）—— 所以排查线上问题一律用 Python 那一侧量。

## 7 它证不了什么

到目前只有**一帧、一队人数（5+5）、一台机器**上的一次读数。**不许**写成「已证明通用」：另一局、另一个人的编队、下一次握手落在哪个边缘，都还没证过。
