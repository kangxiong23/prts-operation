# 槽：三态 × 载荷 × 置信度

> 状态：讨论中 ｜ 见 [README](README.md)


> 它曾叫**「格位」**——那个名字与「格」撞车，读起来像"格的位置"。改掉。

| 轴 | 取值 | 谁有 |
| --- | --- | --- |
| **三态** | 未采样 / 已采样但为空 / 有值 | 一律有 |
| **载荷** | 精确(v) / 区间(lo, hi) / 下界(lo) / 上界(hi) / **二维区域** / 未知 | 三态 = 有值 时 |
| **置信度** | 原语算出的连续量，无量纲 | **只有"读"有** |

- **形态不是并列的一个字段，是载荷自己的类型。** 写成并列字段就能构造出 `形态=精确` 而值是 `[15, 16]` 这种自相矛盾的东西。
- **「未知」是"有值"的一种载荷，不是三态的一支。** `有值 + 未知` = "**那里确实有东西，我不知道它是什么**"；`已采样但为空` = "**那里没有东西**"。这两件事混掉就是假事实。
- **区间的两端各自可开放**：一端开放就是「下界」或「上界」。它们与「区间」**共用同一套操作**（操作定义在 §2；**没有独立的"标量区间"类型**——三种载荷就是那套操作的三个具名形态）。
- **二维区域是第六种载荷**（用户裁定；[原语](../视觉层/原语.md) §6 那条"尚未定"就此了结）。判据是「**载荷的区分是"知道得多准"，值的种类是"知道的是什么"**」：`exists` 的有 / 无 · `classify` 的标签 · `heading` 的四方位**不表达精度**，是值的种类，走「精确」的值域；`locate` 的二维区域**表达精度**（区域越小越准），所以是形态。**形状的出处是 §2，词表的出处是本节。**
- **「精确」的值域比"数"宽**（**修正过一次**）：[原语](../视觉层/原语.md) §1 里七条原语有**三条的「精确」不是数**——`exists` 的**有 / 无**、`classify` 的**标签**、`heading` 的**四方位**。所以 `精确(v)` 的 v 收**数 / 布尔 / 字符串**；而**区间 / 下界 / 上界 仍然只收数**（它们是**标量**形态，见 §2）。后续 §2 落「方向」这类类型时值域可能再放宽一格——**补法同资产端口：由第一个用到它的节补**。
- **置信度：原语产生，槽携带**（**调和过一次**）。[概念 §5.4 第 2 条](../../概念设计共识.md) 说"置信度是视觉原语结果的属性，不是字段的属性"，与本节把它放进槽**不矛盾**：原语算出它，字段把读数整体收进槽。**只有"读"有**——算类由费用推算、记类来自部署记录，都没有识别过程；没有时写 `None`，而 `None` 是"**不是读来的**"，不是"置信度为零"。

### 三态是**字段级**的，不是原语级的

一个原语的结果只有两种：**有读数**（载荷 + 分数 + 矩形）或**没有读数**。

- **原语说不出"未采样"**——你调它，它就是采样过了。所以 `未采样` 这一支**在原语内部永远构造不出来**，只有调用方填得出来。
- **原语的"未命中"也不是三态的一支**："我看了，那里没有"是**读数的内容**，不是读数的缺席。

两条推论：

1. **"没调用"与"调了但没能执行"**（被暂停灰罩或特效盖住、前置不满足）**在信息上等价**，都落成字段的**未采样**；原语侧不必为它们分两个态。反过来：**"没能执行"绝不许冒充"未命中"。**
2. **原语的未命中，只有分数够高时才配升格成"已采样但为空"**；分数低时字段只能报**未采样**。这正是三态必须由字段组装的原因——**未命中算不算事实，取决于字段自己的降级策略，原语不知道**。

**一般形式**（覆盖算类与记类）：`未采样` = **还没有任何一条通道为它给出读数**。

- **读类**：原语没跑 / 没能跑（见上）；
- **算类**：**输入不全**——三态往上传染，**不许在输入未采样时凭空算出一个值**；
- **记类**：还没有记录。

**有哪几种原语、每种允许用哪几个载荷** → [视觉层/原语.md](../视觉层/原语.md)。本节只定**结果的形状**与**载荷词表**，**不列原语**。
