# 端口与错误

> 状态：讨论中 ｜ 见 [README](README.md)


**端口有四个**：设备 · 时钟 · 样本 · 资产。

| | 管什么 |
| --- | --- |
| **设备** | 取像（截图）+ **轴上的四个动词**（部署 / 撤退 / 开技能 / 关技能） |
| **时钟** | 墙钟毫秒 |
| **样本** | **难例样本往哪落**——engine 侧发起，实现住 `offline/hardcase/` |
| **资产**（**方法集由第一个用户层补**，见下） | 投影参数 · 格属性 · **路线（形状 + 出怪记录两层）** · **特征库** · **干净关卡背景帧** |

- **取像不是独立端口**，它就是设备的截图。[控制层](../控制层/识别时机.md) 明说"取像与识别是同一件事的两半、没有常驻取像"——留着这个位置，会诱出一条"只取像不识别"的通路，正好违反那条约束；
- **资产是一个端口**（用户裁定，**修正过一次**——早先写作"是端口还是注入的纯数据，待定"）。位置本身是硬性欠的，不是我加的设计：[代码结构](../代码结构.md) 规则一说 **`engine` 永远不 import `offline`**，而上面那些值全是 `offline/assets_gen/` 的产物、**视觉层与设备层都要读**（视觉层要 ROI 的投影，设备层要点击的投影）。所以它们**必须经由契约层暴露的某个东西**到达，由 `runtime/wiring.py` 接上。三条理由：

  1. **"一次注入的纯数据"在资产清单上站不住**：六样的粒度差着数量级——全局一份（特征库）／每关卡一份（格属性 · 路线）／每（关卡 × 时间态）一份（投影参数 · 干净关卡背景帧）。一次注入要么**全读**（所有关卡的背景帧，而一场战斗只用一张），要么只读当前关卡的——**而后者就是按关卡懒取，也就是端口的语义**。所以它不是另一个并列的设计，是端口的一个特例实现；
  2. **换一套资产时两者不等价**：离线重放跑的是**录制当时那一套**，在线跑读的是**当前库**。纯数据把这个选择交给 `runtime`，端口把它封进适配器——**"换一套"退化成"换一个适配器"**，正是规则二那句原话；
  3. **同构**：设备、样本都已经是端口，资产没有理由单独是数据。

  **方法集由第一个用户层补**（现在有第一个：**投影**，用户层是设备层），并配一条补法规则：**每个方法由它的第一个用户层在用到时补；补的时候只加方法，不改端口本身。** 理由：五个访问点的返回类型**分属不同层**（投影在这一层 §2 · 格属性在状态层/地形 · 路线 / 特征库 / 背景帧在资产生成器），**一开始就定等于替那些层发明类型**；
- **UI 布局常量不在资产端口里**（用户裁定）：它**不进资产库**（[资产生成器](../资产生成器/README.md)：它的值在设计代码时定），因为它**不是生成物**；但设备层与视觉层都要读它，而两者互不 import——所以**它住在这一层**，类型与值都在这里。它是常量，不需要懒取、也不需要换一套，没有理由走端口；
- **样本是一个端口，方法集 = 一个方法**（用户裁定）：**落一份样本**。位置同样是硬性欠的，出处也是规则一：难例采集的**触发点在线**（槽自己发现不确定、组装发现账不平），而**实现住 `offline/hardcase/`**。触发集与落盘内容见[采集与验收](../采集与验收/README.md) §1、[难例采集](../采集与验收/难例采集.md) §1。它因此和设备、资产一样，按构造就被端口完备性测试覆盖。
  **空实现住 `offline/hardcase/port.py`，名字是 `EmptySamplePort`**（T4 落地）：**"什么都不做"就是它的规格** —— 离线验收不需要采集，而一个会偷偷攒东西的空实现会让"离线跑过一遍"留下副作用。**所以它算"接上了"**，不进 `PORT_GAPS`；真实现（上限 · 冻结 · 分池）随采集器一起来，那时端口一个字都不用改。
  **`submit` 的载荷现在是不透明的**（`object`）：它的形状由**第一个用户层**（`offline/hardcase/`）在用到时收窄成具名类型，收窄时只改这一栏、不改端口——同资产端口那条补法规则。

  **为什么是一个方法，而不是按三层触发各开一个**：三层触发产出的**是同一份东西**（[难例采集](../采集与验收/难例采集.md) §1 那七部分），区别只在"谁触发 · 留几条 · 落在哪个池子里"——**上限、冻结、分池全是 `offline/hardcase/` 的事**。**端口是边界，策略在实现侧**；写成一个方法，端口就不必跟着触发层数变；
- **端口必须"纯"到 replay 适配器能满足**（[设备层](../设备层.md)）："离线重放不是特例代码"的落地条件就是**换一个适配器**，所以端口里**不许出现"现在真的是游戏在跑"这类信息**。这也正是[代码结构](../代码结构.md) 里那条**端口完备性测试**的输入——它按构造就能抓出上面这个欠账。

**错误模型 = 三种**（[接口层/执行与失败](../接口层/执行与失败.md) §4）：

| | 含义 |
| --- | --- |
| **拒绝** | 不合法 / 前提不吻合 / 版本认不出 → **整段不执行**，附哪一项不吻合 |
| **降级** | 照常返回，但进快照页眉的[存疑清单](../状态层/快照.md)，槽自身带三态与形态 |
| **中止** | 跑到一半坏了 → 返回**跑到哪一帧** + 哪些已确认生效 |

**铁律上类型**：错误集里**不许有"部分成功"这一支**。工具不报"我尽力了"，只报三态。
