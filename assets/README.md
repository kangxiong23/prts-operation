# assets

生成物。由 `src/ark/offline/assets_gen/` 产出，引擎只读它。

| 目录 | 内容 | 进版本库 |
| --- | --- | --- |
| `gamedata/` | 游戏数据库：从官方数据派生 | **不进** —— 体积大，纯派生，可重建 |
| `features/` | 特征库：识别点与模板 | 进 —— 体积小，半人工，clone 下来即用 |
| `terrain/` | 地形资产与格坐标到像素的投影参数 | 进 —— 同上 |

## 判据

**体积大且可重建的不进，体积小或含人工产出的进。**

游戏数据库是前者；特征库和地形资产里有人工确认过的部分，重建成本高于存储成本，所以进。

## 注意

地形资产必须携带"格坐标 → 像素"的投影参数。不带投影参数的地形资产在另一台设备上没用。
