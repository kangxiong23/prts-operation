# 帧样本 / 灰菱形

**「技能可关闭」那个灰色菱形**的测试夹具 —— 一格一帧，每帧一块 `300×420` 的原生裁剪。

用户给的语义：**黄 = 技能可释放 · 灰 = 技能可关闭**。两个图标**同位置、同外框、不同色**，
里面的字形也不同（黄的是黑爆形、灰的是一个浅灰方块）。

## 这是什么，从哪来

从 `data/precheck/cd/`（一局真机战斗每 3 秒截一张、连截 61 张）裁。那一批全帧是 gitignored
的临时产物，所以把要用的那几块搬进版本库，让验收能反复跑。

裁剪口径照 [`../场上干员/`](../场上干员/README.md)：窗口取 `(1517, 136)` 起 `300×420`
（原生像素，一个都不缩）；取区由**血条左上角 `(1597, 476)` − `BARS_IN_WINDOW`** 折出来
（`operator_ui_window()`），也就是 `(1557, 156, 240, 360)`。

| 文件 | 内容 |
| --- | --- |
| `cdNN.png` | 10 块 `300×420` 的原生像素裁剪 |
| `index.json` | 每块的原点、尺寸、源帧路径与**源帧 sha256**（钉住「这块出自哪一帧」） |
| `取材.json` | 每一块的**真值**（灰菱形在 / 不在）、取区与出处 |
| `README.md` | 这一份 |

## 真值怎么读

**每一块都明写**「灰菱形在」或「灰菱形不在」—— 与 [`../场上干员/`](../场上干员/README.md)
那批不一样（那批的「不在」是靠**不写**来暗示的）。理由：灰的进来之后，「不写」这种约定
会让「漏写一条」与「真的不在」分不开。

**真值里一个分数都没有**：分与余量由秤（把那帧重跑一遍链）现算。

- **在（8 条）**：`cd26` · `cd18` · `cd35` · `cd49` · `cd33` · `cd46` · `cd41` · `cd02`
  —— 技能开着、那个灰菱形在那一格上（有几块被技能特效与 `+840` 那些绿字压着一部分）；
- **不在（2 条）**：`cd03` · `cd08` —— 那一格上是**墙**（镜头已经不在这位干员身上了）。
  这两块是**同一格的「没有」**，不是「另一个干员的没有」。

**另外 14 条「不在」不在这批里**：它们在 [`../场上干员/`](../场上干员/README.md) 那批
（那 16 块里 `cd01_c` · `cd12_a` 两块是**灰的在**，其余 14 块灰不在 —— 其中 8 块**黄的在**）。
灰那条链的验收跨这两批读，见单元测试 `test_close_diamond_verdicts_match_the_batch_truth`。

## 模板从哪来

`assets/features/close_diamond/diamond.npz`，`48×48`，取自 **`data/precheck/cd/cd24.png`**
画布 `(1646, 216)` 起那一块（中心 = 那个白方块的中心 `(1670, 240)`）。

**那一帧不在这批里、也不在任何一批夹具里** —— 《视觉层/识别方法》§已定 那条纪律：图标模板
不许取自验收批的帧。灰菱形在 cd 那批里出现得很密（60 帧里 58 帧有），所以挑得出一张
**完全没被任何夹具用过**的帧当模板源。

**模板尺寸是量出来的**：同一批真值上，`48×48` 的空档是 **0.4542**、`64×64` 是 **0.2196**、
`80×80` 只剩 **0.0801** —— 框一大就把**两个图标共有的那个菱形外框**也框进来，黄的那条会
开始在灰的帧上给分。所以取框**只圈住「白方块 + 紧邻那圈暗底」**这一小块。

## 两条线（读数）

空档 **0.299424 … 0.761464（宽 0.462040）**；两条线取**空档三等分** ⇒
`CLOSE_DIAMOND_ABSENT_SCORE = 0.4534` · `CLOSE_DIAMOND_SOLID_SCORE = 0.6075`，
两侧余量各 **≈ 0.1540**。推导与那 **26 条真值**都写在 `src/ark/engine/vision/field.py`
那两个常量下面。

## 没覆盖到什么

- **暂停态**：这批与场上干员那批**全是常速帧**，暂停态下那个图标自己在动那件事**没测**；
- **灰的分正好落在两条线之间**那一档：真帧一条都没有（空档是量出来的，两簇离得很开），
  那一支只有合成用例（单测里把判据换成一个固定分数）；
- 其余：见 [`../场上干员/README.md`](../场上干员/README.md) 的「没覆盖到什么」—— 这批只补
  **灰菱形那个布尔**，血条 / 技力条那两条链不在这里。

## 怎么重跑

    这一批是用 data/probe/gray_build.py 建的（临时脚本，不进仓）。
    重跑 = 把 cd 帧上 (1517, 136) 起 300x420 那一块拷出来，再跑一遍真值。

**仓里没有写它的生成脚本**（与 [`../先粗后细/`](../先粗后细/README.md) 那批一样）。

## 这一层不判断「够不够」

读数、两簇、空档、覆盖都在这里与 `field.py` 里；**「够不够」是规划者的事。**
