# 帧样本 / 倒计时数字

备战席卡片**正中那个倒计时数字**（`54.7` 这种）的**测试夹具**。原生分辨率下的**底部一条横带**，一帧一文件。

## 它为什么单独一批

那串数字用的**不是出厂字形表那一套**（`1` 带底衬线、笔画更粗 —— [视觉层/识别方法](../../../docs/10-规格/视觉层/识别方法.md) §已定），
所以它不是"再抓几帧"的问题，是**要新建一套粗体字形资产**。
这一批就是那套资产的**取材来源 + 验收材料**：素材要有，值也要有，而且要能回答"这套字形是不是只对我给它看的那几帧管用"。

## 这是什么，从哪来

从 `data/precheck/cd/`（**一局真机战斗、每 3 秒一张、连 61 张**）里裁的 **4 帧**。窗口与另一批（`备战席`）完全一样：
`(300, 1040)` 起、`2500×220`，**裁的是原生像素，一个像素都没缩**。

**为什么单开一批、不并进 `备战席`**：那一批是**另一件事**（卡片怎么排 · 每张多少费 · 状态是是/否），
而这一批只关心**环心那 120 px 见方里的那串数字**。两批同时改，等于两条链的取材混在一起，
回头分不清"这个阈值是照着哪一批调的"。

**`cd08` 不在这一批里**（它在那 61 张里，秒数也读到了）—— 因为它的秒数**已经在 `备战席/取材.json` 里给过了**，
在这一批里当不了验收，而当取材又没带来任何新数字。**要拿它调字形，从 `备战席/取材.json` 那边取。**

## 里面有什么

| 文件 | 内容 |
| --- | --- |
| `cdNN.png` | 4 帧备战席横带（`cd01` · `cd09` · `cd20` · `cd30`） |
| `index.json` | 每张的原点、尺寸、源帧路径与**源帧 sha256** |
| `取材.json` | **哪几帧的真值给执行者** |

## 选帧是按「十个数字占全了」选的

这是这一批唯一的作用，所以它是硬条件。取 "取材 + 验收" 合起来数：

| 帧 | 再部署中的那些卡的秒数 | 这一帧给了哪几个数字 |
| --- | --- | --- |
| `cd01` | 32.2 · 39.5 · 54.7 · 36.0 · 64.2 · 16.0 | 0 1 2 3 4 5 6 7 9 |
| `cd30` | 4.0 · 38.1 · 3.4 | 0 1 3 4 **8** |
| `cd09` | 9.5 · 16.8 · 32.0 · 67.0 · 66.4 · 54.2 · 13.3 · 41.5 | **0–9 全** |
| `cd20` | 34.3 · 68.4 · 33.6 · 21.4 · 8.8 | 1 2 3 4 6 8 |

**`7` · `8` · `9` 是最稀的三位**（`cd01` 里一个 `54.7`、`cd30` 里一个 `38.1`、`cd01` 里一个 `39.5`）。
它们**恰好都在验收帧里又各出现一次**（`67.0` · `16.8` · `9.5`）—— 素材最薄的那三位正好用来验"会不会 generalize"。

**按位点一遍**（机器数的，出处是 `tests/spec/countdown_spec.py` 的 D4 —— 手抄的数会静默过期）：

```
0×5  1×6  2×6  3×12  4×10  5×5  6×9  7×2  8×5  9×2  小数点×22
```

**一位都没有"只有一张样本"的** —— 最少的 `7` 与 `9` 各有两张。

**这一句数的是「取材 + 验收」**（上一段那个口径）。**建表只能吃取材那一份** ——
两批 `取材.json` 合起来 17 张卡 49 位，按**那一份**数：`7` 两张、**`8` 只有一张**
（`cd30` 的 `38.1`，模板就是它自己）。见
[视觉层/识别方法](../../../docs/10-规格/视觉层/识别方法.md) §已知的缺口。

## 取材与验收是分开的两批

`取材.json` 里那 2 帧（`cd01` · `cd30`）是**给执行者开发用的**。
另外 2 帧（`cd09` · `cd20`）**不告诉它值**，是验收用的。

其中 `cd09` 是**全新的**：它不在任何一批的取材表里，执行者**连这一帧都没见过**。

**`cd01` 的秒数，执行者其实已经在 `备战席/取材.json` 里见过了**（那一批的"再部署"那一栏带秒数）——
所以它在这一批里**只能当取材**，当验收就是自欺。`cd30` 则是全新的。

## 怎么用：把裁剪还原成画布

`index.json` 每条都记了 `origin` 与 `size`，所以能把裁剪**贴回**一张 2800×1260 的画布 ——
**这样 ROI 的取法仍然是真的在被测**，而不是把 ROI 预先替它做好。
加载走 `ark.offline.bench.batch.load_batch`，喂进识别链走 `ark.offline.bench.feed.replay_frames`，**全程不用真机**。

**它没有 `facts`**：抓这批帧的时候没记前提头，所以**它不能用来验设备事实那条路**。
`index.json` 里那个 `shot` 整数是这一批自己的额外字段，**不是格式的一部分**。

**它也不写"每张卡多少费"**：这一批只验倒计时那一列，费用是另一条链的事
（那张亮卡面读不出来的欠账记在 [视觉层/备战席](../../../docs/10-规格/视觉层/备战席.md) §尚未定）。
