# 帧样本 / 红罩

**「那层红罩底下是谁」的测试夹具** —— 一组「同一张卡的同一块画面，一次没罩、一次罩着」的**配对**。

## 这是什么，从哪来

来自 `data/precheck/cd/`（**一局真机战斗里每 3 秒截一张、连截 61 张**）。那批全帧是 gitignored 的临时产物，所以把**要用的那一条**搬进版本库，让验收能反复跑。

裁剪口径 · 命名 · 清单字段 · 取材的写法**照 [`../备战席/`](../备战席/README.md) 那一批**：窗口 `(300, 1040)` 起、`2500×220`（原生像素，一个都不缩），一帧一文件，帧名就是 `cdNN`。

| 文件 | 内容 |
| --- | --- |
| `cdNN.png` | 8 帧备战席横带 |
| `index.json` | 每张的原点、尺寸、源帧路径与**源帧 sha256**（钉住「这份裁剪出自哪一帧」） |
| `取材.json` | **哪几对是标定、哪几对是验收**，以及「罩下是谁」那条真值从哪来 |

**为什么是这 8 帧**：它们是 4 对配对的两端。每一对里那张卡在**同一帧对的两个时刻**一次罩着、一次干净，而**卡数相同、其余卡位只差一次亮度**（见下）。

## 配对凭什么算配对（`_pair_ok`）

**不许拿「同一张立绘、不同帧」蒙混** —— 所以判据不是「看起来像」，是四条能跑的结构条件：

1. **两帧卡数相同**（卡数不同直接拒）；
2. **恰有一个卡位的罩状态不同** —— 零个或两个以上都不算配对；
3. **其余每个卡位在两帧之间只差一次亮度**：逐通道仿射，斜率落在 `0.9…1.1`、残差 rms ≤ 3。实测这一层有个**逐卡片的亮度漂移**（可部署高亮 / 费用不足压暗），所以「逐像素相等」这条在真帧上一次都不成立，能成立的只有「相等 + 一次亮度」；
4. **那个卡位自己**差一次仿射，残差 rms ≤ 12。

**它会拒什么**：`cd01`（9 张）配 `cd60`（11 张）→ 卡数不同；同一行里第二个卡位换过人 → 第 3 条；拿两张不同干员的卡去配 → 第 4 条（实测配对 8.9–10.1，拿别的卡位去配 12.2–16.5）。

**第 4 条与模型同形，这一条要记着**：它挡得住「明显不是同一块」，但它**不是**「罩子可解」的独立证据 —— 那个只有全局一组四参数才谈得上。

## 标定与验收是分开的

| 集 | 配对 |
| --- | --- |
| **标定**（定参数用） | `cd14#1 → cd15#1` · `cd22#9 → cd23#9` |
| **验收**（只读数，不回头调参数） | `cd27#6 → cd28#6` · `cd37#4 → cd59#4` |

两集**不相交**，而且是**按对分**的：验收那两对没有参与定任何一个参数。

## 「罩下是谁」这条真值从哪来

**不是目视的，也不是拿编队页的库反推的** —— 是拿**同一张卡后来干净了那一帧**、喂**同一条链**（`roster_scores`）读出来的。每一对在 `取材.json` 里都记了那次读数：过没过线、余量多少。

**这条真值自己是有前提的**：它假设「那张卡后来干净了还是同一个人」。判据那四条正是为这件事量的 —— 卡数没变、其余卡位只差一次亮度。但它**证不到底**：如果那张卡恰好在那一帧被换掉了，这四条看不出来。

## 它同时是一批基准集

按[基准集](../../../docs/10-规格/采集与验收/基准集.md) 的格式，`index.json` 是**第 1 版**。加载它走 `ark.offline.bench.batch.load_batch` —— **全程不用真机**。

**它没有 `facts`**：抓这批帧的时候没记前提头。

## 库在哪

卡面库借 [`../点名/编队页.json`](../点名/编队页.json) 指的那一帧（与这批**不同源**，那是常态）。这一批只放**配对关系与真值**，不另拷一份库。
