# dsh/skills

这个模式专属的技能（skill）放这里，由 `../bundle/cordis.patch.yml` 里的 `customSkillDirs` 指过来。

技能文件本身在磁盘上，**不在 preset 里** —— preset 不提供文件操作，装 bundle 不会把技能文件带过来。分发时要注意这一点。

## 放什么

**使用手册**——这套系统怎么用、一次作业怎么走、每个环节会看到什么。

**拆成多份**，一份 = 一个作业环节；**入口那份负责索引其余各份**（候选五份见下）。

**设计要求在 [docs/10-规格/AI侧/skill.md](../../docs/10-规格/AI侧/skill.md)**——genre 判据 · 分份四条 · 候选五份 · 可检验形式。**这里不重复。**

## 不放什么

- **"你不许…"这类自律要求** → 手册只写**系统的性质**（[skill.md](../../docs/10-规格/AI侧/skill.md) §1）
- 工具定义与参数规则 → 那是引擎的事（`src/ark/engine/api/`）
- 静态事实（字段名 · 方法清单 · 算子 · 干员 · 敌人 · 地形 · 出怪）→ 由 `查资料` 从引擎取
- 游戏机制本身 → 那是 `docs/10-规格/资产生成器/游戏数据库.md` 的事
