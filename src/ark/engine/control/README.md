# ark.engine.control

**职责**：取像节拍、时间态切换（常速 / 慢放 / 暂停）、条件判定、主循环。

## 两段式条件

AI 每次要给出**两个**条件：粗条件（在常速判定，容差大）和暂停条件（进入慢放后再判）。

这么切是因为常速下取像有延迟，细条件判不准；而 1/10 速下 1 个逻辑帧约等于 3 个取像周期，所以**不需要更高取像帧率**。

## 时间基

维持一个只在非暂停时走、慢放下按倍率折算的秒表。**不读游戏自己的时钟** —— 那既不可靠也没必要。

**允许 import**：`ark.contracts`、`ark.engine.control`
**禁止 import**：其它 `ark.engine.*`、`ark.offline.*`
