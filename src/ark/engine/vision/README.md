# ark.engine.vision

**职责**：像素 → 数值 + 置信度。它回答「这个位置读到多少、有多确信」，**不回答「这是什么意思」**。

放什么：原语（颜色、统计量、模板）、遮挡掩码、ROI 定义与解析、前帧跳算、特征库的读取与校验、从帧到观测的链路。

## 三条不能越的线

1. **不解释语义。** 「这里有个红条」是视觉层；「这是敌人血条」是状态层的事。
2. **输出必须带三态。** 未采样 / 已采样但为空 / 有值，三者绝不混成一个"空"。
3. **必须能被离线驱动。** 它只从设备端口拿帧，从不自己去找设备。

**允许 import**：`ark.contracts`、`ark.engine.vision`
**禁止 import**：其它 `ark.engine.*`、`ark.offline.*`

## 不在这里

- 这些数怎么变成游戏状态 → `../state/`
- 特征库怎么生成 → `../../offline/assets_gen/`
