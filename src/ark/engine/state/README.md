# ark.engine.state

**职责**：把视觉层读到的数值组织成「当前战场是什么状态」：干员、敌人、费用、格子、场地机制。

## 这一层的验收标准

**不是识别准确率，是零假事实。**

- 数不清敌人的时候，要明确说「数不清」并给出下界或区间，**而不是猜一个精确数字**。
- 每个字段必须能表达三种情况：未采样 / 已采样但为空 / 有值。三者混成一个"空"就是假事实的来源。

这条是全项目最重要的一条，写在 `confidence` 相关的模块里，不是写在文档里。

**允许 import**：`ark.contracts`、`ark.engine.state`
**禁止 import**：其它 `ark.engine.*`、`ark.offline.*`

## 不在这里

- 像素怎么读出来 → `../vision/`
- 状态怎么存成时间片 → `../timeline/`
