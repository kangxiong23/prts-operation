# ark.engine.timeline

**职责**：带时序的记录（时间片 + 动作流），以及轴本身的格式与版本。

## 轴必须携带环境前提

一份轴如果不带前提，那「审批之后重放等于复现」就是假的。至少要带：分辨率、帧率、练度指纹、游戏版本、合约词条、队伍，外加格式版本。

**认不出前提就报错拒绝执行，不静默跳过。** 静默跳过会让一份错的轴看起来是对的，这比报错危险得多。

**允许 import**：`ark.contracts`、`ark.engine.timeline`
**禁止 import**：其它 `ark.engine.*`、`ark.offline.*`

## 不在这里

- 什么时候暂停 → `../control/`
- AI 怎么读写这些记录 → `../api/`
