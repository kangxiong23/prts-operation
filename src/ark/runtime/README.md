# ark.runtime

**职责**：配置、依赖注入、入口。**唯一可以 import 所有其它包的地方。**

**允许 import**：全部
**禁止 import**：无（但除了它自己，别人不许 import 它）

## 为什么依赖注入要单独一个包

因为 `engine` 的六个子包互不 import，总得有人把它们接起来。接在别处会让那个模块变成隐藏的组装点；集中在这里，**"谁依赖谁"就只有一个地方需要读**。

`wiring.py` 是这个包的核心，`cli.py` 与 `app.py` 只是它的两个外壳。

## 入口形态

引擎是一个**进程**，不是一个被 import 的库。所以入口是命令行，不是 `__init__` 里导出的函数。

## 不在这里

- 各个部件本身 → `../engine/`
- 离线工具 → `../offline/`
