# ark.offline.assets_gen

**职责**：从官方数据与界面截图，生成三样东西：

| 产物 | 落到哪 | 进不进版本库 |
| --- | --- | --- |
| 游戏数据库 | `assets/gamedata/` | **不进**（体积大、纯派生） |
| 特征库 | `assets/features/` | 进（体积小、半人工） |
| 地形资产 | `assets/terrain/` | 进（体积小、半人工） |

## 标注的大头是免费的

生成器不该被当成"要人工标一堆东西"的工具：

- **我方部署指令本身就是干员身份的答案** —— 不需要额外标。
- **关卡出怪表给出敌人粗标签** —— 不需要额外标。

真正需要人工的只有界面型资产，而那部分的规模只随「UI 与识别点种类数」增长，**不随关卡数增长**。
