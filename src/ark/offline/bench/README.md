# ark.offline.bench

**职责**：把录下来的帧喂回线上识别链路，量出结果。这是「视觉层必须能被离线驱动」那条地基约束的**验收手段**。

## 量的是什么

不是识别准确率，是**零假事实**：

- 报出来的每一件事，是不是真的？
- 数不清的时候，有没有老实说数不清（给下界或区间），而不是猜一个精确数字？

前者高、后者不达标，比两者都平庸要危险得多。

**允许 import**：`ark.contracts`、`ark.engine.*`、`ark.offline.*`

## 不在这里

- 用什么样的帧 → `../hardcase/`
- 设备端口怎么换成重放 → `../../engine/device/`
